# 수학 전투 RPG — 구현 제안

## 확인한 프로젝트

- Unity 6000.3.12f1, 2D URP 템플릿.
- Assets 검색 기준 사용자 C# 스크립트 없이 SampleScene이 있는 시작 상태.
- 첨부한 시스템 기획서와 스토리 문서를 기준으로 진행.

## 첫 구현 범위: 플레이 가능한 전투 프로토타입

1. 별도 Prototype 씬: 지면, 플레이어, 적, 카메라, 전투 UI를 구성한다.
2. 좌우 이동, 점프, 숙이기, 즉시 평타, 즉시 약한 스킬을 구현한다.
3. 적은 공격을 미리 알리는 동작 후 공격하며 점프/숙이기로 피할 수 있다.
4. 명중 시 히트스톱, 넉백, 피격 이펙트, 효과음을 적용한다.
5. 큰 스킬은 개념 판단 객관식 문제를 거쳐 발동한다. 조준→차징→발동으로 단계 풀이를 연결한다.
6. 오답 소거와 제한된 정령 힌트, 가벼운 초반 체력 페널티를 제공한다.
7. 첫 훈련소 교관 시험과 스킬북 보상으로 작은 진행 루프를 완성한다.
8. 체크포인트 저장/불러오기와 정령의 시간 되감기 재도전을 구현한다.

첫 버전은 임시 도형 그래픽과 자체 제작 예제 문항으로 구현한다. 정식 아트, 전체 문제은행, 4챕터 완성 콘텐츠는 이후 단계다.

## 모듈

Assets/MathRPG 아래 Core, Player, Combat, Enemy, MathQuiz, Progression, UI, Data, Editor를 둔다.
문항, 스킬, 교관, 대사, 챕터는 ScriptableObject 데이터로 분리한다.
씬 생성 도구를 제공하여 에디터에서 재현 가능하게 구성한다.

## 후속 단계

- 챕터1 확장: 훈련소 4곳, 교관 4종, 선택 보스, 라이벌1 결투.
- 계산기: 클릭 기반 숫자/식 블록, 취소/초기화, 문법 검증, 기능별 해금.
- 성장: 스킬북 숙련도, 개념 선수관계, 보충 던전, 개념 도감.
- 챕터2: 정령 마을 3곳, 유물 3개, 수호 정령 보정, 집합체 보스.
- 챕터3: 인간 마을 3곳, 인장 획득과 라이벌2 강제 패배 연출.
- 챕터4: 거점 없는 진행, 각성, 라이벌 리매치, 최종보스 3페이즈, 에필로그.

## 유지할 기획 규칙

- 전투 타격감을 먼저 검증한다. 평타는 문제 없이 발동한다.
- 플레이어 UI에 학년/단원평가/부모의 기대를 목표명으로 표시하지 않는다.
- 상시 룬 장갑 폭주 리스크를 추가하지 않는다.
- NPC 혼잣말은 이동을 멈추지 않으며 수집 목록으로 기록하지 않는다.
- 부모의 편지는 챕터2 발신, 챕터3 미개봉 답장, 챕터4 개봉/파기로 유지한다.
- 정령은 평행세계 대응 인물이며 정체 공개는 챕터4 심상세계다.
- 연립방정식, 작도, 확률통계, 고3 범위는 제외한다.

## 승인 시 채택할 임시 설정

- 첫 훈련소는 문제풀기형 교관으로 시작한다. 이후 순서는 추가 결정한다.
- 문제 입력 동안 전투를 일시 정지한다. 실제 전투 흐름을 보고 조정한다.
- 예제 문항, 피해량, 힌트 횟수, 숙련도 단계는 Inspector에서 수정 가능하게 한다.
- 최종보스 부활 방식과 미정 세계관 설정은 확정된 것으로 취급하지 않는다.

## 검증

Unity 컴파일 확인 후 Prototype 씬에서 이동/회피, 명중, 스킬 정답/오답, 힌트 소진, 교관 보상, 사망/재시작, 저장/불러오기를 확인한다.
에디터 실행 검증을 수행할 수 없는 환경이면 실제 수행한 검증과 남은 확인을 구분하여 보고한다.

## 현재 변경

사용자가 첫 구현을 승인하여 Assets/MathRPG에 런타임 코드, 데이터 정의, 씬/프리팹 생성 도구와 테스트 코드를 추가했다.
실행 방법과 구현 범위는 Docs/PrototypeGuide.md에 정리했다.
이전 상태는 SampleScene이 있는 템플릿이었고, 기존 씬을 직접 수정하지 않고 별도 프로토타입을 생성하도록 구성했다.
사용자의 후속 요청에 따라 Unity 실행/테스트 검증은 사용자에게 맡긴다.

### 훈련소 확장

승인된 문제풀이 → 사냥 → 보물상자 → 스파링 순서의 네 훈련소를 추가했다.
교관별 조건 충족 시 다음 훈련소를 해금하고, 스킬북을 한 번 지급한다.
저장 형식 v2에 훈련소별 기록을 추가하고 기존 v1 첫 교관 기록을 이전한다.
후속 승인으로 라이벌1 결투를 추가했다. 훈련소 네 곳의 수료 뒤 진입하며, 동시 문제풀이·위력 감소·체력 절반에서의 패턴 교체·승리 대사와 v3 완료 저장을 포함한다.

### 첫 정령 마을

승인된 챕터2 첫 구간을 추가했다. 라이벌 승리 후 숲으로 이동하고, 불신하는 마을 정령의 의뢰를 받아 T1 보스와 싸운다.
삼각형 성질·합동 도식 문제, 오답 생명 흡수, 첫 유물 획득과 v4 진행 저장을 포함한다. Unity 실행 검증은 사용자가 진행한다.

### 두 번째 정령 마을

물결 마을을 추가했다. 삼각의 유물 획득 후 이동하며, 평행사변형·닮음·피타고라스 도식 문제와 T1 물거울 정령, 두 번째 유물을 포함한다.
마을 사이 왕복과 마을별 진행 기록을 v5에 저장한다. v4의 첫 마을 기록은 유지한다. 실행·테스트는 사용자가 진행한다.

### 세 번째 정령 마을

달고리 마을과 T1 달무리 정령을 추가했다. 원의 성질·삼각비·원기둥 도식 문제, 원의 유물 획득, 세 마을 왕복과 v6 저장을 포함한다.
기존 마을 기록을 유지한다. 수호 정령 각성과 집합체 보스는 후속 범위이며, 실행·테스트는 사용자가 진행한다.

### 수호 정령과 챕터2 클라이맥스

유물 3개로 수호 정령 각성, 숲 한정 공격 보정, T2 집합체와 완료 대사를 추가했다.
체력 피해·정답/오답에 따른 패턴 강화/완화, 절반 체력에서의 공격 순서 변경, 세 문항 완성 시 결속 해제 타격을 사용한다. 임시 수치는 ForestClimax 데이터에서 조정한다.
v7은 기존 기록에 각성·챕터2 완료를 추가한다. 실행·테스트는 사용자가 진행한다.
