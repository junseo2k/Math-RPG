# 보스 상세: 시간 역행 (1장 보스3 · 1장 최종)

> 상위 문서: `Docs/Design/GameDesign.md` 3장 (본편 보스 후보, 보류)
> 표기: **[확정]** / **[미결]**

---

## 1. 개요 [확정]

- 1장(탄생) 세 번째이자 마지막 시종 보스. 스테이지 9(20:00~21:00 구간의 끝). 처치 시 시험판 클리어.
- 권능: **시간 역행**(1장 핵심 권능). 지나간 것을 되돌린다.
- 권능 적용 2가지: **공격 역재생**, **플레이어 위치 되감기**.
- 패턴: 이전 보스 요소를 쓰지 않는 **독립 패턴**.
- **2단계**: 체력 절반 이하에서 **위치 되감기가 추가**된다.
- AI: 규칙 기반. 처치 시 권능 획득은 시험판에서 제외(본편).
- 세계관 주의: 역행은 **보스의 권능**이다. 플레이어의 사망·재탄생은 시간 역행이 아니다(확정 규칙).

**기획 의도**: 1단계에서 "지나간 공격이 거꾸로 돌아온다"를 익히고, 2단계에서 "내가 지나온 자리로 끌려간다"를 하나 더 얹는다. 지금 위치뿐 아니라 **과거의 공격과 과거의 나**까지 관리하게 하는 1장의 마무리.

## 2. 패턴

### 2-1. 고리 파동 + 역재생 [확정, 2026-10-19 탑다운 전환으로 형태 변경] (1·2단계)
| 항목 | 내용 |
|---|---|
| 발동 조건 | 일정 간격마다 |
| 1차 | 보스가 바닥을 내리쳐 **고리 모양 파동이 보스를 중심으로 퍼져 나감** |
| 역재생 | 고리가 최대 반경에 닿으면, **같은 고리가 거꾸로 보스 쪽으로 오므라듦** |
| 플레이어 행동 | 대시 무적으로 고리 통과 → 오므라드는 고리를 **한 번 더** 통과 (또는 최대 반경 밖으로 피함) |
| 결과 | 파동에 닿으면 피해 |

### 2-2. 위치 되감기 [확정] (2단계부터)
| 항목 | 내용 |
|---|---|
| 발동 조건 | 체력 절반 이하에서 무작위 간격마다 (타이밍을 외워 피하지 못하게, 2026-10-25 변경) |
| 예고 | 플레이어가 **돌아갈 위치에 잔상**이 미리 보임 |
| 결과 | 예고가 끝나면 플레이어가 그 잔상 위치로 되돌려짐(위치만, 체력 등은 그대로) |
| 플레이어 대응 | **잔상 자리가 위험해지지 않게** 관리(예: 되돌아오는 파동 경로를 피함). 취소 불가 |

### 2-3. 세부 규칙 [확정]
- 고리는 **보스 중심으로 모든 방향**에 퍼진다. 두께 1(대시 거리보다 얇아 대시로 통과할 수 있음).
- 내리치기 전 예비 동작(보스가 팔을 드는 자세 + 색 변화)으로 발동을 알린다.
- 최대 반경에 닿은 고리는 잠시 멈추고 **반시계 나선** 표시 후 오므라든다(역재생 예고).
- 오므라든 고리는 보스 위치에 닿으면 사라진다.
- 잔상 위치 = **예고 시작 시점의 N초 전 플레이어 위치**. 잔상은 반투명 플레이어 모양으로 표시.
- 되감기는 피해가 아니므로 대시 무적과 상관없이 발동한다. 파동 피해에는 대시 무적이 적용된다.
- 2단계 진입 시 보스가 잠깐 멈추고 반시계 나선 연출(전환을 알림).
- 보스는 천천히 플레이어 쪽으로 걷는다. 몸에 닿아도 피해 없음(다른 보스와 일관).
- 순간 정지장은 보스에게 통하지 않는다(확정 규칙). 파동도 멈추지 않는다.

## 4. 조절 수치 [확정·임시 기본값, 플레이테스트 후 조정]

| 분류 | 항목 | 기본값 |
|---|---|---|
| 기본 | 보스 체력 / 2단계 진입 | 400 / 50% |
| 이동 | 걷기 속도 | 1.0 |
| 고리 파동 | 간격 / 예비 동작 / 퍼지는 속도 / 두께 / 최대 반경 / 피해 | 3.5초 / 0.6초 / 7 / 1 / 12 / 20 |
| 역재생 | 최대 반경에서 멈춤(예고) / 오므라드는 속도 | 0.5초 / 7 |
| 위치 되감기 | 간격(최소~최대, 무작위) / 예고 / 되돌아갈 시간(N초 전) | 6~10초 / 1.0초 / 3초 |
| 2단계 전환 | 멈춤 연출 | 1.0초 |

- 실제 값은 `Assets/Resources/CombatBalance.asset` (메뉴 Tools/전투 밸런스 열기)에서 조절한다. HP·피해는 플레이어 HP 100 기준.
