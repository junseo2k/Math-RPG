# 보스 상세: 시간 축적 (1장 보스1)

> 상위 문서: `Docs/Design/GameDesign.md` 3장 (본편 보스 후보, 보류)
> 표기: **[확정]** / **[제안]** / **[미결]**

---

## 1. 개요 [확정]

- 1장(탄생) 첫 번째 시종 보스. 스테이지 3(18:00~19:00 구간의 끝).
- 권능: **시간 축적**. 시간이 지날수록 힘을 쌓고, 가득 차면 한 번에 방출한다.
- AI: 규칙 기반.
- 처치 시 권능 획득은 시험판에서 제외(본편).

**기획 의도**: 첫 보스이므로 "보고 → 예측하고 → 피한다"는 기본 대응 하나만 요구한다. 축적 게이지가 차는 것을 보고 방출 타이밍을 읽는 것이 핵심 학습이다.

---

## 2. 패턴

### 2-1. 축적 → 방출 [확정]

| 항목 | 내용 |
|---|---|
| 발동 조건 | 전투 시작부터 일정 간격마다 축적 스택 +1. 최대 스택 도달 시 방출 |
| 플레이어 행동 | 방출 예고를 보고 보스에게서 멀어지거나, 대시 무적으로 통과 |
| 결과 | 예고 후 **보스 중심 충격파**. 범위 안의 플레이어는 피해 |
| 방출 후 | 스택 0으로 초기화, **짧은 탈진**(움직이지 않음 = 공격 기회) → 다시 축적 |
| 방해 | 없음. 플레이어는 스택을 줄일 수 없다 |
| 조절 수치 | 스택 증가 간격, 최대 스택, 예고 시간, 충격파 반경, 충격파 피해, 탈진 시간 |

### 2-2. 근접 돌진 [확정]

| 항목 | 내용 |
|---|---|
| 발동 조건 | 축적 중, 일정 간격마다 |
| 플레이어 행동 | 돌진 경로 옆으로 비켜서거나 대시로 회피 |
| 결과 | 플레이어 방향으로 돌진. 닿으면 피해 |
| 조절 수치 | 돌진 간격, 돌진 속도, 돌진 거리, 돌진 피해 |

### 2-3. 보조 규칙 [확정]
- 방출 예고와 탈진 중에는 돌진하지 않는다(패턴이 겹치지 않게).
- 축적 스택을 보스 머리 위 게이지로 표시해 방출 타이밍을 읽을 수 있게 한다.
- 접촉 피해는 **돌진 중에만** 있다. 평소에는 몸에 닿아도 안전하다.
- 탈진 중 받는 피해는 평소와 같다(추가 배율 없음).
- 돌진 전 짧은 예비 동작(멈춤·색 변화)으로 회피 타이밍을 알린다.
- 예고 중에는 보스가 깜빡이고, 방출 순간 충격파 범위를 잠깐 표시한다.

## 3. 승리·실패 [확정]

| 상황 | 처리 |
|---|---|
| 보스 체력 0 | 보스 처치 → `GameFlow.ClearStage()` (시각 +1시간, 다음 방) |
| 플레이어 체력 0 | `GameFlow.PlayerDied()` → 다음 날 18:00 재탄생 |

---

## 4. 조절 수치 [확정·임시 기본값, 플레이테스트 후 조정]

| 분류 | 항목 | 기본값 |
|---|---|---|
| 기본 | 보스 체력 | 300 |
| 축적 | 스택 증가 간격 / 최대 스택 | 1.5초 / 5 |
| 방출 | 예고 / 충격파 반경 / 충격파 피해 / 탈진 | 1.0초 / 3.5 / 30 / 2.0초 |
| 돌진 | 간격 / 예비 동작 / 속도 / 거리 / 피해 | 3초 / 0.4초 / 12 / 6 / 15 |

- 실제 값은 `Assets/Resources/CombatBalance.asset` (메뉴 Tools/전투 밸런스 열기)에서 조절한다. HP·피해는 플레이어 HP 100 기준 (2026-10-25 1장 보스1로 복귀하며 환산).
