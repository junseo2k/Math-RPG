# 보스 상세: 시간 유예 (1장 보스2)

> 상위 문서: `Docs/Design/GameDesign.md` 3장 (본편 보스 후보, 보류)
> 표기: **[확정]** / **[미결]**

---

## 1. 개요 [확정]

- 1장(탄생) 두 번째 시종 보스. 스테이지 6(19:00~20:00 구간의 끝).
- 권능: **시간 유예**. 일어날 일을 미뤄 둔다. 공격도, 피해도 늦게 도착한다.
- AI: 규칙 기반. **단일 단계**(체력에 따른 패턴 변화 없음).
- 기본 공격: **원거리 투사체**(축적 보스의 근접 돌진과 차별화).
- 처치 시 권능 획득은 시험판에서 제외(본편).

**기획 의도**: 축적 보스에서 배운 "예고를 보고 피한다"에 **시간차**를 하나 얹는다. 지금 피한 공격이 나중에 다시 오고, 지금 맞은 피해가 나중에 들어온다. 플레이어는 "지금"과 "조금 뒤"를 함께 봐야 한다.

## 2. 패턴

### 2-1. 투사체 + 궤적 예약 [확정]
| 항목 | 내용 |
|---|---|
| 발동 조건 | 일정 간격마다 투사체 발사 |
| 1차 | 투사체가 날아감. 맞으면 **즉시 피해** |
| 궤적 예약 | 투사체가 지나간 자리에 **점선 궤적**이 남음 |
| 2차 | 일정 시간 뒤 그 궤적 전체에 피해가 **다시 발동**. 맞으면 **유예 피해**(2-2) |
| 플레이어 행동 | 투사체를 이동·대시로 피하고, 남은 점선 궤적에서 발동 전에 벗어남 |

### 2-2. 피해 유예 [확정]
| 항목 | 내용 |
|---|---|
| 적용 대상 | **궤적 예약 공격(2차)에 맞았을 때만**. 투사체 직격(1차)은 즉시 피해 |
| 결과 | 피해가 바로 들어오지 않고 **보류**되었다가 유예 시간 뒤 적용 |
| 플레이어 대응 | 유예 시간 동안 **보스를 때리면 보류된 피해가 줄어듦** |
| 보스 처치 시 | 남은 유예 피해는 **소멸** |
| 플레이어 사망 시 | 재탄생으로 초기화(임시 상태) |

### 2-3. 세부 규칙 [확정]
- 투사체는 발사 순간 **플레이어 위치를 향해** 직선으로 날아가 벽에서 사라진다(대각선 궤적이 생겨 방 공간이 나뉨).
- 궤적 발동 직전 0.3초 동안 점선이 밝게 깜빡여 발동을 알린다.
- 대시 무적은 궤적 발동에도 적용된다(기존 대시 무적 규칙과 일관).
- 보스 적중 1회당 보류된 피해 감소(기본 15 = 궤적 1회분).
- 보류된 피해는 플레이어 머리 위에 **모래시계 + 숫자**로 표시하고, 남은 시간이 줄어드는 것을 보여준다.
- 보스는 천천히 방 안을 비스듬히 떠돌다 경계에서 튕기며, 몸에 닿아도 피해 없음(일반 적·축적 보스와 일관).
- 순간 정지장은 보스에게 통하지 않는다(확정 규칙). 투사체·궤적도 멈추지 않는다.

## 3. 승리·실패 [확정]

| 상황 | 처리 |
|---|---|
| 보스 체력 0 | 보스 처치 → 유예 피해 소멸 → `GameFlow.ClearStage()` (시각 +1시간, 다음 방) |
| 플레이어 체력 0 | `GameFlow.PlayerDied()` → 다음 날 18:00 재탄생. 유예 피해 적용으로 0이 되어도 동일 |

## 4. 조절 수치 [확정·임시 기본값, 플레이테스트 후 조정]

| 분류 | 항목 | 기본값 |
|---|---|---|
| 기본 | 보스 체력 | 350 |
| 이동 | 이동 속도 | 1.5 |
| 투사체 | 발사 간격 / 속도 / 직격 피해 | 2.0초 / 8 / 15 |
| 궤적 예약 | 발동까지 지연 / 발동 예고 / 궤적 폭 / 발동 지속 | 2.0초 / 0.3초 / 0.6 / 0.3초 |
| 피해 유예 | 유예 피해 / 유예 시간 / 보스 적중당 감소 | 15 / 3.0초 / 15 |

- 실제 값은 `Assets/Resources/CombatBalance.asset` (메뉴 Tools/전투 밸런스 열기)에서 조절한다. HP·피해는 플레이어 HP 100 기준. 유예 시간은 플레이어의 `DeferredDamage`에 있다.
