# 시험판 A 요구사항

- 기준: `Docs/Design/GameDesign.md` (원문: `Docs/Design/PlanningHandoff.md`), 결정: `Docs/SliceA/CombatDecisions.md` (이하 CD)
- 범위: 시험판 A만 다룬다. 본편·시험판 B 기능은 "제외"로만 표기하고 상세화하지 않는다.
- 상태 표기: **[확정]** 원문 확정 / **[승인]** CD에서 사용자 승인 (2026-10-17) / **[임시]** 임시 수치 / **[제안]** / **[미결]** / **[미표기]**
- [임시] 수치는 Inspector 초기값으로만 쓰며 최종 수치가 아니다.
- CD의 승인 내용은 시험판 A 기준이다. 본편 적용 여부는 [미결]이다.
- **2026-10-25 범위 변경 [확정]**: 시험판 A는 **1장(탄생)을 완벽하게 만드는 것**을 목표로 한다. 보스 1명(시험판 보스) → 1장 보스 3명(축적·유예·역행, `Docs/Bosses/01~03`). 시험판 보스(SliceBoss)는 코드만 남긴다. CD6·CD7(보스 결정 시점·패턴 재선택)은 시험판 보스 기준으로 승인된 것이라 1장 보스 적용 방식은 M-23으로 남긴다.

## 1. 시험판 목적

핵심 검증 질문 **[확정]**:
> 역행으로 보스 공격을 다시 판단하고, 피해와 위치를 복원하는 선택이 재미있는가?

- A 완성 후 B로 확장한다. B는 동일 보스·스테이지 구조에 정지/가속을 추가한다. **[확정]**
- 따라서 A의 보스와 스테이지 구조는 B에서 그대로 재사용된다는 전제로 만든다.
- 시험판 성공 기준(수치·판정 방법): 14장 참조 **[제안/검증 전]**

## 4. 한 판의 진행 흐름

```
순환 시작 (18:00, 포션 1개)
 아래 묶음을 보스 3명(축적 → 유예 → 역행)에 대해 반복:
 → 일반 스테이지 → 클리어: 특성 3지선다 + 50G
 → 일반 스테이지 → 클리어: 특성 3지선다 + 50G
    → 클리어 후 숨은 통로 개방 → (발견 시) 상점
 → 보스 스테이지 → 처치: 역행 전용 특성 3지선다 + 유물 1개 + 100G + 기억 조각 10, 시각 +1시간
 3번째 보스(역행) 처치 → 1장 클리어 → 결과 → 영구 성장 화면 → 새 순환으로 재도전 가능
사망 → 결과 → 영구 성장 화면 → 다음 순환 18:00부터 일반 스테이지 1 재시작
```

| 묶음 | 스테이지 | 보스 | 시각 (처치 후) |
|---|---|---|---|
| 1 | 1·2·3 | 시간 축적 | 19:00 |
| 2 | 4·5·6 | 시간 유예 | 20:00 |
| 3 | 7·8·9 | 시간 역행 (1장 최종) | 21:00 |

| 단계 | 요구사항 | 상태 |
|---|---|---|
| 시작 | 권능 역행, 무기 검 고정. 포션 1개 보유 | [확정] / 포션 [승인] CD11 |
| 일반 스테이지 클리어 | 마지막 적 HP 0 프레임에 확정 → 통합 특성 풀(역행 전용 + 공용 4)에서 3개 제시, 1개 선택 | [확정] / 확정 시점 [승인] CD8 |
| 일반 스테이지 보상 G | 50G | [임시] |
| 상점 통로 | 보스 직전 일반 스테이지(2·5·8) 클리어 확정 후 개방 (9-1 참조) | [승인] CD11 / 보스 직전마다 2026-10-25 |
| 보스 클리어 | 보스 HP 0 프레임에 확정 → 역행 전용 특성 3개 중 1개(일반 특성 선택과 중복 지급 안 함) + 무작위 유물 1개 | [확정] / 확정 시점 [승인] CD8 |
| 보스 보상 G / 기억 조각 | 100G / 10개 | [임시] |
| 보스 처치 후 | 1·2번째 보스: 보상 후 다음 스테이지. 3번째 보스: 결과 → 성장 화면 → 새 순환 재도전 | [승인] CD12 / 1장 기준 2026-10-25 |
| 사망 후 | 사망 연출 → 결과 → 성장 화면 → 18:00 재시작 | [승인] CD8, CD12 |
| 시간 표시 | 보스 처치마다 +1시간 (18:00 → 21:00), 상단 시계로 표시. 일반 스테이지는 시각 변화 없음 | 보스 문서 [확정] / 표시 방식 M-19 |

A의 한 판 특성 선택 기회는 총 9회(일반 6 + 보스 3)다.

## 12. 기능별 검증 기준

각 항목은 구현 여부를 예/아니오로 판정한다.

### 진행
- [ ] (일반 2 → 보스 1) × 3, 총 9스테이지가 축적 → 유예 → 역행 보스 순으로 진행된다.
- [ ] 보스 처치마다 시각이 +1시간(19:00 → 20:00 → 21:00) 되고, 3번째 보스 처치 시 1장 클리어가 된다.
- [ ] 시작 시 권능은 역행, 무기는 검으로 고정되고 포션 1개를 가진다.
- [ ] 일반 스테이지 클리어마다 특성 후보 3개가 제시되고 1개를 고를 수 있다.
- [ ] 일반 스테이지 특성 후보는 역행 전용 4 + 공용 4종에서만 나온다.
- [ ] 한 번의 제시에 같은 특성이 두 번 나오지 않고, Lv.3 특성은 나오지 않는다.
- [ ] 후보 카드에 현재·다음 레벨과 다음 레벨 효과가 표시되고, 건너뛸 수 없다.
- [ ] 보스 클리어 시 역행 전용 특성 3개 중 1개를 고르고, 일반 특성 선택은 추가로 주어지지 않는다.
- [ ] 보스 클리어 시 유물 1개가 지급되고, 이미 가진 유물은 나오지 않는다.
- [ ] 유물 풀이 비면 유물 대신 특성 선택 기회가 주어진다.

### 플레이어 조작
- [ ] 탑다운에서 8방향 이동, 마우스 조준 방향 단일 기본 공격이 동작한다.
- [ ] 회피는 8방향으로 쓸 수 있고 쿨타임만으로 제한되며, 회피 중 무적이다.
- [ ] 회피 무적 중 적 공격과 겹치면 "회피 성공" 유물 효과가 발동한다.
- [ ] 공격 중 회피를 누르면 공격이 취소되고 회피한다.
- [ ] 피격 시 경직·넉백·피격 무적이 적용되고, 경직 중 공격·회피는 안 되며 역행·포션은 된다.
- [ ] 포션은 즉시 사용되고, 포션이 없거나 HP가 최대면 사용되지 않는다.
- [ ] 보호막이 HP보다 먼저 깎이고 스테이지 종료 시 사라진다.
- [ ] 같은 종류의 % 효과가 합산되고, 고정 추가 피해는 % 증가 영향을 받지 않는다.

### 보스
- [ ] 보스 3명이 각 보스 문서(`Docs/Bosses/01~03`)의 [확정] 패턴·세부 규칙대로 동작한다.
- [ ] 축적 보스: 머리 위 게이지가 차면 예고(깜빡임) 후 충격파, 방출 후 탈진. 축적 중에만 돌진한다.
- [ ] 유예 보스: 투사체 직격은 즉시 피해, 궤적 발동은 유예 피해. 유예 피해는 머리 위 모래시계·숫자와 HP 바 파란 구간으로 보이고, 보스를 때리면 줄어든다.
- [ ] 역행 보스: 고리 파동이 퍼졌다 오므라들고, 체력 절반 이하에서 2단계(몸 색 변화) + 무작위 간격 위치 되감기가 추가된다.
- [ ] 보스 공격에 맞으면 경직·넉백·피격 무적이 적용되고, 회피 무적 중 겹치면 회피 성공이 발생한다.

### 역행
- [ ] 역행 사용 시 플레이어·적의 위치, 체력, 공격 진행 상황이 역행 거리 전 상태로 복원된다.
- [ ] 복원 후 정지 연출 동안 입력이 무시되고, 재개 후 짧은 무적이 적용된다.
- [ ] 역행 직후 무적 중에는 회피 성공이 발생하지 않는다.
- [ ] 플레이어가 받은 피해와 적에게 준 피해가 함께 취소된다.
- [ ] 처치 확정 전의 일반 적은 역행으로 되살아난다.
- [ ] 회피 쿨타임, 포션 보유 수·쿨타임, 보호막이 복원된다.
- [ ] 역행하면 복원 지점 뒤에 생긴 보스 공격 오브젝트(유예 투사체·궤적, 역행 파동)가 사라지고 유예 피해도 그 시점으로 돌아간다.
- [ ] (M-23 결정 후) 보스 공격 결정 전후로 역행했을 때 1장 보스의 이어감·재선택 동작이 결정 내용대로 동작한다.
- [ ] 일반 적은 역행 후 이전 공격을 반복한다.
- [ ] 역행 쿨타임은 역행으로 되돌아가지 않는다.
- [ ] 스테이지 시작 후 2초가 지나기 전에 역행하면 시작 시점으로 복원된다.
- [ ] 쿨타임 중 입력은 무시되고 사용 불가 피드백이 나온다.
- [ ] 경직·공격·회피·포션 사용 중에도 역행할 수 있다.
- [ ] 상점·특성 선택 화면에서는 역행할 수 없다.
- [ ] 역행 관련 수치를 Inspector에서 바꾸면 코드 수정 없이 반영된다.

### 확정 처리
- [ ] HP 0 프레임에 사망이 확정되고 이후 역행할 수 없다.
- [ ] 사망과 같은 물리 프레임에 역행을 입력하면 역행이 우선한다.
- [ ] 보스·마지막 적 HP 0 프레임에 처치·클리어가 확정되고, 남은 보스 공격·투사체가 제거되며 플레이어가 무적이 된다.
- [ ] 플레이어와 보스가 같은 프레임에 HP 0이 되면 처치가 우선한다.
- [ ] "전투당 1회" 효과는 스테이지마다 다시 사용할 수 있다.

### 역행 특성·유물
- [ ] 잃어버린 찰나: 피해를 받은 뒤 역행하면 취소된 피해 비율만큼 보호막을 얻는다.
- [ ] 되찾은 일격: 역행으로 취소된 준 피해의 비율이 다음 적중에 고정 추가 피해로 더해진다.
- [ ] 반복되는 운명: 결정 이후로 복귀한 공격의 위험 범위가 더 일찍 표시된다. (1장 보스 적용은 M-23)
- [ ] 과거의 잔상: 취소된 구간에서 적중시킨 공격을 잔상이 같은 시간 흐름대로 다시 실행한다.
- [ ] 역사의 파편: 역행 후 3초 내 첫 공격 피해가 증가한다.

### 상점·재화·포션
- [ ] 일반 클리어·보스 처치 시 G가 지급된다.
- [ ] 보스 직전 일반 스테이지(2·5·8) 클리어 후 숨은 통로가 열리고, 들어가지 않고 다음 스테이지로 가면 사라진다.
- [ ] 상점 안에서는 스테이지 시간이 멈추고 역행·전투가 불가하다.
- [ ] 상점은 포션과 유물 2개만 팔고, G가 부족하거나 포션이 3개면 해당 구매가 불가하다.
- [ ] 상점 유물과 보스 보상 유물이 같은 풀을 쓰고 중복되지 않는다.
- [ ] 나오면 통로 앞으로 돌아오고 통로가 닫힌다.

### 사망·영구 성장
- [ ] 사망 시 결과 → 성장 화면을 거쳐 일반 스테이지 1부터 재시작한다.
- [ ] 재시작 시 특성·유물·G가 초기화되고 포션이 1개가 된다.
- [ ] 3번째 보스 처치(1장 클리어) 후 결과 → 성장 화면 → 새 순환으로 재도전할 수 있다.
- [ ] 기억 조각과 영구 성장 구매 내역이 재시작 후와 게임 재실행 후에도 유지된다.
- [ ] 기억 조각은 G와 별도로 표시·관리된다.
- [ ] 1단계 3항목을 비용만큼 구매할 수 있고, 최대 레벨·조각 부족 시 구매가 불가하다.
- [ ] 구매한 성장이 다음 순환부터 적용된다.

### 시험판 목적
- [ ] 핵심 검증 질문에 답할 수 있는 플레이테스트가 가능하다. 판정 기준은 14장 [제안/검증 전] (M-1)

## 14. 성공 기준 (M-1) — [제안/검증 전]

- 이 장의 지표 정의와 합격선은 모두 **[제안/검증 전]**이다. 외부 플레이테스트로 검증하기 전에는 확정이 아니다.
- 평가 범위: 조작감, 전투, 역행, 보상, 영구 성장, 순환, 반복 플레이, 종합 만족도
- 대상: 외부 플레이어 5~10명. 진행 절차·설문은 `Docs/Test/PlayChecklist_SliceA.md` "외부 플레이테스트" 참조
- 결과와 성공 여부는 플레이테스트 후 별도로 기록한다. 이 문서에는 적지 않는다.

### 14-1. 평가 시점

| 시점 | 범위 | 측정 |
|---|---|---|
| 첫 플레이 | 게임 시작부터 첫 사망 또는 첫 클리어까지 (최대 15분) | 설문 A, 관찰, 로그 |
| 순환 이후 | 첫 사망·클리어 후 영구 성장 화면부터 자유 플레이 (15분) | 설문 B, 관찰, 로그 |
| 전체 | 세션 전체 (플레이 약 30분) | 로그, 관찰 |

### 14-2. 정량 지표

설문은 모두 5점 척도(1 전혀 아니다 ~ 5 매우 그렇다). 문항 번호는 `PlayChecklist_SliceA.md` 설문 기준.

| # | 지표 | 정의 [제안] | 수집 방법 | 판정 시점 | 잠정 합격선 |
|---|---|---|---|---|---|
| S1 | 치명적 오류 | 진행 불가, 멈춤, 저장 손상, 의도와 다른 사망 판정의 발생 건수 | 관찰 + 로그(오류) | 전체 | 0건 [제안/검증 전] |

### 14-3. 참고 지표 (합격선 없음)

로그로 모으되 합격 판정에는 쓰지 않는다. 정량 지표가 미달일 때 원인을 찾는 데 쓴다.

| 지표 | 보는 이유 |
|---|---|
| 보스전 1회당 역행 사용 횟수 | 역행을 실제로 전략으로 쓰는지 |
| 역행 직후 같은 공격 회피 성공률 | "다시 판단"이 실제로 일어나는지 |
| 재선택 / 이어감 경험 횟수 | 두 규칙을 모두 겪었는지 (S4 해석용) |
| 첫 역행 사용 시점 | 안내 없이 역행을 발견하는 데 걸린 시간 |
| 역행 사용 불가 시도 횟수와 이유 | 쿨타임·규칙을 이해하는지 |
| 사망 원인 (패턴별) | 특정 패턴이 너무 어렵거나 읽히지 않는지 |
| 상점 통로 발견율 | 숨은 통로 단서가 충분한지 |
| 특성 선택 분포 | 특정 특성만 고르거나 피하는지 |
| 순환 횟수, 영구 성장 구매 항목 | 순환 이후 흐름이 이어지는지 |

### 14-4. 정성 평가

| 항목 | 수집 방법 |
|---|---|
| 역행을 처음 쓴 순간과 반응 | 관찰 |
| 혼란을 보인 지점 (멈춤, 같은 실수 반복, 질문) | 관찰 |
| 플레이 중 말로 표현한 반응 (생각 말하기) | 관찰 |
| 가장 헷갈린 순간, 역행으로 상황이 바뀐 순간 | 설문 A 자유 의견 |
| 다시 하고 싶은 이유 / 그만두고 싶었던 순간, 하나만 고친다면 | 설문 B 자유 의견 |
| 시험판 전체 인상 | 인터뷰 |

### 14-5. 결과 해석 규칙 [제안]

- 참가자가 5명 미만이면 합격 판정을 하지 않고 참고 결과로만 기록한다.
- 합격선 미달 항목은 14-3 참고 지표와 14-4 정성 평가로 원인을 정리한 뒤, 기획(planner)·구현(dev) 후속 작업으로 넘긴다.
- S5가 범위를 벗어나면 Inspector 수치 조정 후보로 기록한다. 이 문서에서 수치를 바꾸지 않는다.
- 첫 플레이와 순환 이후 값은 항상 따로 기록한다. 둘을 합친 평균을 내지 않는다.
