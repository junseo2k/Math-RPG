## 1. 일반 방

### 1-1. 확정 [확정]
- 형태: **사방이 벽으로 막힌 탑다운 방**. 카메라가 플레이어를 따라 상하좌우로 움직인다. [2026-10-19 탑다운 전환]
- 클리어: 방 진입 시 출구 잠김 → **적 전멸 시 출구 개방**(기존 F4).
- 적 수: 같은 장 안에서 **뒤쪽 방일수록 증가**.
- 구성: 미리 만든 **여러 방 형태 중 매 판 무작위** 선택(로그라이크 변주).

### 1-2. 흐름
```
입구에서 등장 → 출구 잠김 → 적 처치 → 마지막 적 처치 시 출구 개방
→ 출구 진입 → GameFlow.ClearStage() → 다음 방
```

| 항목 | 내용 |
|---|---|
| 플레이어 행동 | 방 안을 이동하며 적 처치 후 출구로 이동 |
| 발동 조건 | 방 진입 |
| 결과 | 적 전멸 → 출구 개방 → 출구 진입 시 다음 스테이지 |
| 실패 처리 | 플레이어 체력 0 → 사망·재탄생(기존 F6) |
| 예외 [확정] | 적이 방 경계 밖으로 나가면 제거하고 처치로 계산(진행 막힘 방지) |

### 1-3. 방 세부 [확정]
| 항목 | 내용 |
|---|---|
| 방 크기 | 가로 30~40 × 세로 20~25유닛(화면 약 2×2개 분량) [2026-10-19 탑다운 전환, 수치 임시] |
| 방 형태 수(시험판) | 3종: **A 빈 방**, **B 기둥 4개**, **C 중앙 가림벽(좌우로 돌아감)** |
| 무작위 규칙 | 한 판 안에서 같은 형태는 모든 형태를 한 번씩 쓴 뒤에 다시 나옴 |
| 구덩이(낙사) | 없음. 사방이 벽으로 막혀 있음(입문 부담 감소) |
| 적 배치 | 형태마다 스폰 지점 후보를 두고, 적 수만큼 무작위 선택. 입구 근처(화면 1개 이내)에는 배치하지 않음 |
| 출구 표시 | 잠김: 닫힌 문 + 남은 적 수 표시 / 개방: 문이 열리고 빛남 |
| 카메라 | 상하좌우 추적, 방 경계에서 멈춤 |

### 1-4. 방별 적 수 [확정]
| 1장 스테이지 | 1 | 2 | 4 | 5 | 7 | 8 |
|---|---|---|---|---|---|---|
| 적 수 | 2 | 3 | 3 | 4 | 4 | 5 |

(3·6·9는 보스 방)

## 2. 일반 적: 근접 순찰형

### 2-1. 확정 [확정]
- 근접 순찰형 1종. 순찰 지점 사이를 오가다 플레이어를 발견하면 다가와 **예비 동작 후 벤다**.
- 규칙 기반 AI.

**기획 의도**: 첫 적으로 "예비 동작을 보고 피하거나 먼저 벤다"는 검·대시의 기본 대응을 연습시킨다. 축적 보스의 돌진(예비 동작 → 공격)과 같은 읽기 방식이라 보스전 준비가 된다.

### 2-2. 행동
| 상태 | 발동 조건 | 행동 |
|---|---|---|
| 순찰 | 기본 | 순찰 지점 2곳 사이 왕복. 벽에 막히면 방향 전환 |
| 추적 | 플레이어가 감지 거리 안 | 플레이어 쪽으로 8방향 이동 |
| 공격 | 플레이어가 공격 사거리 안 | 예비 동작 → 베기 → 공격 후 대기 |
| 피격 | 검에 맞음 | 짧은 경직 |
| 사망 | 체력 0 | 제거, 방의 남은 적 수 -1 |

- 추적 중 플레이어가 감지 거리를 벗어나면 순찰로 복귀.

### 2-3. 세부 규칙 [확정]
- 접촉 피해 없음. **베기에만 피해**(축적 보스의 "돌진 중에만 접촉 피해"와 일관).
- 예비 동작 중 피격 시 공격이 취소되지 않음(예비 동작은 "피할 신호"로만 사용).
- 처치 보상 없음(보상 구조는 기획 미결).
- 세계관 [확정]: 시종들이 시간을 멈춰 굳힌 밤의 파수꾼. 이름 미정.

### 2-4. 조절 수치 [확정 기본값]
| 항목 | 기본값 |
|---|---|
| 체력 | 3 (검 3회) |
| 순찰 속도 / 추적 속도 | 2 / 3.5 |
| 감지 거리 | 6 |
| 공격 사거리 | 1.2 |
| 예비 동작 | 0.5초 |
| 베기 피해 | 1 |
| 공격 후 대기 | 1.0초 |
| 피격 경직 | 0.2초 |
