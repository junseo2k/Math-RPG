# 시험판 A 플레이 체크리스트

조작: ←→ 이동 · Space 점프 · Shift 회피 · A 공격 · S 역행 · Q 포션 · ↑ 통로 진입 · F10 역행 위치 미리보기 · F11 디버그(G +100, 기억 조각 +10)

## ① 진행 (일반 2 + 보스 1)
- [ ] 시작하면 선택 화면 없이 1스테이지. HUD 둘째 줄에 `0G  기억 조각 N  포션[Q] 1  역행[S] 준비`
- [ ] 적 전멸 → 출구에 닿으면 특성 카드 3장, 상단 "+50G", 카드 배지 "신규 Lv.1"
- [ ] 카드를 고르면 2스테이지로 이동

## ② 특성 규칙
- [ ] 같은 특성을 다시 고르면 배지가 "Lv.1 → Lv.2"
- [ ] 한 번에 뜬 3장에 같은 특성이 겹치지 않음
- [ ] 보스 처치 후에는 "역행 전용" 카드만 나옴
- [ ] 오른쪽 아래 디버그 목록에 보유 특성과 레벨이 맞게 표시됨

## ③ 상점
- [ ] 2스테이지 적 전멸 후 **입구 뒤쪽 벽 앞**에 깜빡이는 통로가 생김
- [ ] 통로 안에서 ↑ → 상점 열림. 포션 30G, 유물 80G / 100G
- [ ] G가 모자라면 "구매 불가"
- [ ] 나가기 → 통로가 사라짐. 통로에 들어가지 않고 출구로 가면 이번 판에서는 다시 열 수 없음

## ④ 보스와 역행
- [ ] 내려베기에 맞은 직후 S → 하단 줄 "취소 Slash 제외: 재선택 예정", 보스가 다른 공격을 고름
- [ ] 탄막·낙하에 맞은 직후 S → "이어감"
- [ ] 역행 후 쿨타임 20초 동안 S → "사용 불가: 쿨타임"
- [ ] 보스 처치 → 보상(유물 획득 + "기억 조각 +10") → 결과 화면 → "영구 성장으로" → 성장 화면

## ⑤ 역행 특성·유물 (F11로 G를 모아 상점에서 사거나 보상으로 얻기)
- [ ] 잃어버린 찰나: 맞고 역행하면 HUD에 "보호막 N"
- [ ] 시간 절약: 역행 쿨타임이 20초보다 짧게 시작
- [ ] 과거의 잔상: 적을 때리고 역행하면 같은 박자에 반투명 잔상 판정
- [ ] 철의 태엽: 최대 HP +20

## ⑥ 사망과 순환
- [ ] 일부러 죽으면 2초 뒤 성장 화면. 기억 조각 유지
- [ ] "다음 순환 시작" → 1스테이지. G 0, 특성·유물 없음, 포션 1개, 일차 +1
- [ ] 성장에서 "최대 HP" 구매 → 다음 판 최대 HP 110
- [ ] 플레이를 껐다 켜도 기억 조각·성장 레벨 유지 (`persistentDataPath/slice_a_save.json`)

## 알려진 한계 (코드 점검으로 확인)
- "반복되는 운명"은 탄막에 위험 범위 표시가 없어 효과가 보이지 않음 (내려베기·돌진·낙하에서만 확인 가능)
- HUD 시계는 보스 처치 전까지 18:00에 머무름 (1시간 전진은 보스 처치 때만)
- 상점·성장 화면은 임시 IMGUI
- 씬에 `GameFlow`가 직접 배치돼 있으면 거기 저장된 값이 코드 기본값보다 우선함 (미확인)

결함을 발견하면 재현 절차(어느 스테이지, 어떤 입력, 기대 결과 vs 실제 결과)를 함께 적어 주세요.
