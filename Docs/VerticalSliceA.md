## 1. 시험판 목적

핵심 검증 질문 **[확정]**:
> 역행으로 보스 공격을 다시 판단하고, 피해와 위치를 복원하는 선택이 재미있는가?

- A 완성 후 B로 확장한다. B는 동일 보스·스테이지 구조에 정지/가속을 추가한다. **[확정]**
- 따라서 A의 보스와 스테이지 구조는 B에서 그대로 재사용된다는 전제로 만든다.
- 시험판 성공 기준(수치·판정 방법): **[미결]**

## 4. 한 판의 진행 흐름

```
순환 시작 (18:00, 포션 1개)
 → 일반 스테이지 1 → 클리어: 특성 3지선다 + 50G
 → 일반 스테이지 2 → 클리어: 특성 3지선다 + 50G
    → 클리어 후 숨은 통로 개방 → (발견 시) 상점
 → 보스 스테이지 → 처치: 역행 전용 특성 3지선다 + 유물 1개 + 100G + 기억 조각 10
 → 결과 → 영구 성장 화면 → 새 순환으로 재도전 가능
사망 → 결과 → 영구 성장 화면 → 다음 순환 18:00부터 일반 스테이지 1 재시작
```

| 단계 | 요구사항 | 상태 |
|---|---|---|
| 시작 | 권능 역행, 무기 검 고정. 포션 1개 보유 | [확정] / 포션 [승인] CD11 |
| 일반 스테이지 클리어 | 마지막 적 HP 0 프레임에 확정 → 통합 특성 풀(역행 전용 + 공용 4)에서 3개 제시, 1개 선택 | [확정] / 확정 시점 [승인] CD8 |
| 일반 스테이지 보상 G | 50G | [임시] |
| 상점 통로 | 일반 스테이지 2 클리어 확정 후 개방 (11장 참조) | [승인] CD11 |
| 보스 클리어 | 보스 HP 0 프레임에 확정 → 역행 전용 특성 3개 중 1개(일반 특성 선택과 중복 지급 안 함) + 무작위 유물 1개 | [확정] / 확정 시점 [승인] CD8 |
| 보스 보상 G / 기억 조각 | 100G / 10개 | [임시] |
| 보스 처치 후 | 결과 → 성장 화면 → 새 순환 재도전 | [승인] CD12 |
| 사망 후 | 사망 연출 → 결과 → 성장 화면 → 18:00 재시작 | [승인] CD8, CD12 |
| 시간 표시 | A의 3스테이지가 18:00~06:00 중 어느 구간인지, 화면 표시 여부 | [미결] |

A의 한 판 특성 선택 기회는 총 3회(일반 2 + 보스 1)다. 같은 특성을 3번 모두 골라야 Lv.3에 도달한다.

| 피격 | 피해 → 경직 + 공격자 반대 방향 넉백 → 피격 무적. 진행 중 공격 취소. 피격 무적 중 추가 피격 무시 | [승인] CD1 |

| 입력 우선 | 공격 중 회피 입력 시 공격 취소 후 회피 | [승인] CD1 |
| 포션 | 동작 없이 즉시 사용. 포션 없거나 HP 최대면 사용 불가 | [승인] CD1 / [미표기] |
| 피해 계산 | 준 피해 = 공격력 × (1 + 피해 증가% 합) × (치명타 시 배율) + 고정 추가 피해 | [승인] CD2 |

| 중첩 | 같은 종류 %는 합산. 고정 추가 피해는 % 영향 없음 | [승인] CD2 |
| 보호막 | 지속 시간 없음, HP보다 먼저 소모, 스테이지 종료 시 소멸, 여러 효과 합산 | [승인] CD2 |
| 전투 단위 | 전투 = 스테이지 1개. "전투 시작" = 스테이지 시작, "전투당 1회" = 스테이지당 1회 | [승인] CD8 |

| 복원함 | 복원하지 않음 |

## 12. 기능별 검증 기준

각 항목은 구현 여부를 예/아니오로 판정한다.

### 진행
- [ ] 일반 2 → 보스 1 순서로 3스테이지가 진행된다.
- [ ] 시작 시 권능은 역행, 무기는 검으로 고정되고 포션 1개를 가진다.
- [ ] 일반 스테이지 클리어마다 특성 후보 3개가 제시되고 1개를 고를 수 있다.
- [ ] 일반 스테이지 특성 후보는 역행 전용 4 + 공용 4종에서만 나온다.
- [ ] 한 번의 제시에 같은 특성이 두 번 나오지 않고, Lv.3 특성은 나오지 않는다.
- [ ] 후보 카드에 현재·다음 레벨과 다음 레벨 효과가 표시되고, 건너뛸 수 없다.
- [ ] 보스 클리어 시 역행 전용 특성 3개 중 1개를 고르고, 일반 특성 선택은 추가로 주어지지 않는다.
- [ ] 보스 클리어 시 유물 1개가 지급되고, 이미 가진 유물은 나오지 않는다.
- [ ] 유물 풀이 비면 유물 대신 특성 선택 기회가 주어진다.

### 플레이어 조작
- [ ] 횡스크롤에서 좌우 이동, 단일 점프, 단일 기본 공격이 동작한다.
- [ ] 회피는 지상·공중 모두 쿨타임만으로 제한되고, 회피 중 무적이다.
- [ ] 회피 무적 중 적 공격과 겹치면 "회피 성공" 유물 효과가 발동한다.
- [ ] 공격 중 회피를 누르면 공격이 취소되고 회피한다.
- [ ] 피격 시 경직·넉백·피격 무적이 적용되고, 경직 중 공격·회피는 안 되며 역행·포션은 된다.
- [ ] 포션은 즉시 사용되고, 포션이 없거나 HP가 최대면 사용되지 않는다.
- [ ] 보호막이 HP보다 먼저 깎이고 스테이지 종료 시 사라진다.
- [ ] 같은 종류의 % 효과가 합산되고, 고정 추가 피해는 % 증가 영향을 받지 않는다.

### 보스
- [ ] 보스가 대기 → 결정 → 예고 → 실행 → 회복 순으로 행동하고, 예고 시작 순간에 공격이 결정된다.
- [ ] 보스는 4패턴 중 직전 공격을 제외하고 가중 무작위로 고른다.

### 역행
- [ ] 역행 사용 시 플레이어·적의 위치, 체력, 공격 진행 상황이 역행 거리 전 상태로 복원된다.
- [ ] 복원 후 정지 연출 동안 입력이 무시되고, 재개 후 짧은 무적이 적용된다.
- [ ] 역행 직후 무적 중에는 회피 성공이 발생하지 않는다.
- [ ] 플레이어가 받은 피해와 적에게 준 피해가 함께 취소된다.
- [ ] 처치 확정 전의 일반 적은 역행으로 되살아난다.
- [ ] 회피 쿨타임, 포션 보유 수·쿨타임, 보호막이 복원된다.
- [ ] 짧은 패턴(내려베기·돌진)에 맞은 뒤 역행하면 보스가 다른 공격을 고른다.
- [ ] 긴 패턴(탄막·낙하)에 맞은 뒤 역행하면 보스가 같은 공격을 이어간다.
- [ ] 역행 지점이 정확히 결정 프레임이면 같은 공격을 이어간다.
- [ ] 일반 적은 역행 후 이전 공격을 반복한다.
- [ ] 역행 쿨타임은 역행으로 되돌아가지 않는다.
- [ ] 스테이지 시작 후 2초가 지나기 전에 역행하면 시작 시점으로 복원된다.
- [ ] 쿨타임 중 입력은 무시되고 사용 불가 피드백이 나온다.
- [ ] 경직·공격·회피·공중·포션 사용 중에도 역행할 수 있다.
- [ ] 상점·특성 선택 화면에서는 역행할 수 없다.
- [ ] 역행 관련 수치를 Inspector에서 바꾸면 코드 수정 없이 반영된다.

### 확정 처리
- [ ] HP 0 프레임에 사망이 확정되고 이후 역행할 수 없다.
- [ ] 사망과 같은 물리 프레임에 역행을 입력하면 역행이 우선한다.
- [ ] 보스·마지막 적 HP 0 프레임에 처치·클리어가 확정되고, 남은 보스 공격·투사체가 제거되며 플레이어가 무적이 된다.
- [ ] 플레이어와 보스가 같은 프레임에 HP 0이 되면 처치가 우선한다.
- [ ] "전투당 1회" 효과는 스테이지마다 다시 사용할 수 있다.

### 역행 특성·유물
- [ ] 잃어버린 찰나: 피해를 받은 뒤 역행하면 취소된 피해 비율만큼 보호막을 얻는다.
- [ ] 되찾은 일격: 역행으로 취소된 준 피해의 비율이 다음 적중에 고정 추가 피해로 더해진다.
- [ ] 반복되는 운명: 결정 이후로 복귀한 공격의 위험 범위가 더 일찍 표시된다.
- [ ] 과거의 잔상: 취소된 구간에서 적중시킨 공격을 잔상이 같은 시간 흐름대로 다시 실행한다.
- [ ] 역사의 파편: 역행 후 3초 내 첫 공격 피해가 증가한다.

### 상점·재화·포션
- [ ] 일반 클리어·보스 처치 시 G가 지급된다.
- [ ] 일반 스테이지 2 클리어 후 숨은 통로가 열리고, 들어가지 않고 다음 스테이지로 가면 사라진다.
- [ ] 상점 안에서는 스테이지 시간이 멈추고 역행·전투가 불가하다.
- [ ] 상점은 포션과 유물 2개만 팔고, G가 부족하거나 포션이 3개면 해당 구매가 불가하다.
- [ ] 상점 유물과 보스 보상 유물이 같은 풀을 쓰고 중복되지 않는다.
- [ ] 나오면 통로 앞으로 돌아오고 통로가 닫힌다.

### 사망·영구 성장
- [ ] 사망 시 결과 → 성장 화면을 거쳐 일반 스테이지 1부터 재시작한다.
- [ ] 재시작 시 특성·유물·G가 초기화되고 포션이 1개가 된다.
- [ ] 보스 처치 후 결과 → 성장 화면 → 새 순환으로 재도전할 수 있다.
- [ ] 기억 조각과 영구 성장 구매 내역이 재시작 후와 게임 재실행 후에도 유지된다.
- [ ] 기억 조각은 G와 별도로 표시·관리된다.
- [ ] 1단계 3항목을 비용만큼 구매할 수 있고, 최대 레벨·조각 부족 시 구매가 불가하다.
- [ ] 구매한 성장이 다음 순환부터 적용된다.

### 시험판 목적
- [ ] 핵심 검증 질문에 답할 수 있는 플레이테스트가 가능하다. 판정 기준은 [미결] (M-1)
