# 시험판 임시 시작 능력 3개 (P1-②)

> 상위 문서: `Docs/VerticalSliceSpec.md` F2, `Docs/DevRoadmap.md` P1-②
> 표기: **[확정]** / **[미결]**
> 시험용 임시 능력이다. 정식 시작 능력 10개와 별개이며, 이름에 `[임시]`를 붙인다.

---

## 1. 능력 [확정]

| id | 이름 | 종류 | 효과 |
|---|---|---|---|
| `temp_a` | [임시] 순간 정지장 | 액티브 (S키) | 플레이어 주변 범위의 **일반 적**을 잠시 멈춘다. 보스에게는 통하지 않는다 |
| `temp_b` | [임시] 잔광 | 패시브 | 대시 직후 일정 시간 안의 **다음 검 공격 1회** 피해 +1 |
| `temp_c` | [임시] 가벼운 발걸음 | 패시브 | 이동 속도 +20%, 대시 재사용 대기 -30% |

**기획 의도**: 셋이 각각 다른 플레이(시간 정지로 안전 확보 / 대시-공격 연계 / 기동력)를 유도해, 시작 선택이 플레이에 차이를 만드는지 확인한다.

## 2. 세부 규칙 [확정]

### temp_a 순간 정지장
| 항목 | 내용 |
|---|---|
| 플레이어 행동 | S키 |
| 발동 조건 | 진행 중 상태, 재사용 대기 끝 |
| 결과 | 반경 안 일반 적의 이동·공격 진행이 멈춤. 예비 동작 중이던 적은 멈춘 시간만큼 공격이 늦어짐. 멈춘 적은 파랗게 표시 |
| 실패 처리 | 대기 중 입력은 무시 |

### temp_b 잔광
| 항목 | 내용 |
|---|---|
| 발동 조건 | 대시 사용 |
| 결과 | 유지 시간 안에 휘두른 다음 검 공격 1회 피해 +1. 휘두르면 적중 여부와 상관없이 소모 |
| 실패 처리 | 유지 시간이 지나면 사라짐 |

### temp_c 가벼운 발걸음
- 선택 즉시 적용, 판 동안 유지.

### 공통
- 재탄생 시 모든 효과 해제, 새로 고른 능력 적용(임시 상태 초기화 규칙).

## 3. 조절 수치 [확정 기본값]

| 능력 | 항목 | 기본값 |
|---|---|---|
| 순간 정지장 | 반경 / 정지 시간 / 재사용 대기 | 3 / 1.5초 / 8초 |
| 잔광 | 추가 피해 / 유지 시간 | +1 / 1.0초 |
| 가벼운 발걸음 | 이동 속도 / 대시 대기 | +20% / -30% |
