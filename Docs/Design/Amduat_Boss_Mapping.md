# 암두아트 12시간 × 달의 열두 시종 대응표

> 용도: 세계관·보스 기획 및 취업 포트폴리오의 신화 모티브 출처 정리  
> 작성 기준: 2026-10-25 대화  
> 주의: **게임에서 확정한 권능**과 **암두아트에서 착안한 창작적 해석**을 구분한다. 암두아트 원전이 각 시간 조작 능력을 직접 묘사하는 것은 아니다.

## 1. 장별 권능 구성

| 장 | 주제 | 일반 시종 권능 | 핵심 시종 권능 | 상태 |
|---|---|---|---|---|
| 1장 | 탄생 | 시간 축적, 시간 유예 | 시간 역행 | 기존 기획 기준 |
| 2장 | 존재 | 시간 감속, 시간 공유 | 시간 정지 | 기존 기획 기준 |
| 3장 | 쇠퇴 | 시간 침식, 시간 갱신 | 시간 가속 | 기존 기획 기준 |
| 4장 | 종언 | 시간 분기, 시간 예지 | 시간 순서 | 시간 순서로 변경 확정 |

> **검증 필요:** 개별 보스 권능의 최종 배치와 명칭은 저장된 최신 기획 문서와 대조한 후 확정 표기한다. 특히 일반 시종 외 권능은 과거 대화에서 변경된 이력이 있을 수 있다.

| 밤의 시간 / 게임 시각 | 장 / 주제 | 게임 보스 권능 | 암두아트의 사건·상징(요약) | 게임에서의 재해석 | 상태 |
|---|---|---|---|---|---|

| 제5시간 / 22시 | 2장 / 존재 | 시간 공유 | 소카르의 영역에서 태양의 배를 옮기는 과정 | 여러 존재가 시간을 나누어 부담하는 힘 | 신화 연결 제안 |

| 제8시간 / 01시 | 3장 / 쇠퇴 | 시간 갱신 | 재탄생을 준비하는 존재들과 의복의 상징 | 소모된 상태를 새롭게 바꾸는 존재 | 신화 연결 제안 |
| 제9시간 / 02시 | 3장 / 쇠퇴 | 시간 가속 | 태양의 배가 다음 영역으로 나아감 | 종말을 향해 시간 진행을 앞당기는 존재 | 신화 연결 제안 |
| 제10시간 / 03시 | 4장 / 종언 | 시간 분기 | 익사한 자의 보호와 태양신의 눈 회복 | 소멸과 생존이라는 서로 다른 가능성 | 신화 연결 제안 |
| 제11시간 / 04시 | 4장 / 종언 | 시간 예지 | 마지막 여정의 준비와 시간의 상징 | 아직 오지 않은 순간을 미리 바라보는 존재 | 신화 연결 제안 |
| 제12시간 / 05시 | 4장 / 종언 | 시간 순서 | 재생의 관문을 거쳐 케프리로 재탄생, 일출 | 다음 사건의 순서를 바꾸어 일출을 막는 존재 | 최종 권능 확정 / 신화 연결 제안 |

> **시간 표기:** 각 행의 시각은 해당 보스가 시작하는 게임 내 시간 슬롯이다. 마지막 슬롯은 05:00~06:00이며, 06:00이 일출 경계다.

## 3. 신화와 권능의 연결성 평가

| 연결성 | 해당 권능 | 평가와 주의점 |
|---|---|---|
| 비교적 강함 | 시간 감속, 시간 침식, 시간 갱신, 시간 순서 | 통과의 지연, 아포피스의 방해, 재생 준비, 일출과의 연결이 직관적이다. 다만 시간 조작 자체는 창작이다. |
| 보통 | 시간 축적, 시간 유예, 시간 공유, 시간 가속 | 원전의 장면을 시간의 개념으로 확장한 해석이다. |
| 약함 | 시간 역행, 시간 정지, 시간 분기, 시간 예지 | 원전에 동일한 능력이 직접 등장하지 않는다. 게임만의 재해석이라고 명시해야 한다. |

## 4. 최종 시종 — 시간 순서 권능

### 확정

| 항목 | 규칙 |
|---|---|
| 고유 권능 | 시간 순서 |
| 세계관에서의 역할 | 매일 오전 06:00에 권능을 사용하여 06:00~18:00의 낮 12시간을 생략한다. |
| 시간의 성질 | 과거로 되돌리는 것이 아니라 앞으로 진행할 시간 구간을 건너뛴다. |
| 생략된 낮 | 사건이 발생하지 않는다. |
| 날짜와 기억 | 다음 날짜로 진행하며 NPC들의 기억과 이전 사건의 결과는 유지된다. |
| 비밀 공개 | 최종 시종이 낮을 생략한다는 사실은 게임 막바지에 밝혀진다. |
| 최종 보스 페이즈 | 100~75%: 1장 권능 / 75~50%: 2장 권능 / 50~25%: 3장 권능 / 25~0%: 4장 권능 |
| 전투 중 순서 재배열 | HP 25% 이하에서만 사용한다. 한 번에 세 공격의 실행 순서를 재배열한다. |
| 기존 인과 역전 | 별도의 핵심 권능에서 제외한다. |

### 제안 / 미결

| 항목 | 내용 | 상태 |
|---|---|---|
| 권능 분배 | 최종 시종이 다른 시종에게 시간 권능을 나눠준 존재라는 방향 | 제안, 구체적인 기원 미결 |
| 분배 방식 | 태양신에게서 빼앗은 권능을 분할했는지, 시종들의 권능을 관리하는지 | 미결 |
| 0 HP 발악 | 자신의 죽음이 발생하는 순서를 뒤로 미루는 연출 | 제안, 규칙 미결 |
| 순서 재배열 예고 | 공격 A·B·C를 먼저 제시하고, 바뀐 실행 순서를 읽을 수 있도록 표시 | 제안 |
| 최종 시종 외형 | 케프리 자체가 아니라 재탄생 관문을 차지한 존재 | 제안 |

## 6. 포트폴리오 설명 문구

> 《암두아트》에서 태양신이 밤의 열두 시간을 통과하여 재탄생하는 구조를, 열두 시종의 시간 권능과 4개 장의 보스 전투로 재해석했다. 원전의 각 장면을 그대로 재현하지 않고, 통과·정체·침식·재생·일출 등의 상징을 플레이 규칙으로 번역했다. 마지막 시종은 '시간 순서' 권능으로 낮을 생략하여 영원한 밤을 유지하며, 최종 전투에서는 이전 시종들의 권능을 순차적으로 사용하고 마지막 페이즈에서 세 공격의 순서를 재배열한다.
