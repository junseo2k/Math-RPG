# 태양핵 명세 (Solar Core Spec)

> 작성일: 2026-10-19
> 상위 문서: `Docs/Design/GameDesign.md` 2장(주인공 = 몰락한 태양신), `Docs/SliceA/VerticalSliceA.md`, `Docs/SliceA/CombatDecisions.md`
> 표기: **[확정]** 사용자 확정 / **[미결]** 미정. 미결 항목은 8장에 모아 둔다.
> 모든 수치는 **Inspector에서 조절 가능**하게 노출한다. 아래 수치는 확정된 기본값이다.

---

## 1. 개요 [확정]

- 태양핵은 플레이어(태양신)가 소환하는 **고유 능력**이다.
- 기본 형태는 **고정 설치형**이다. 범위 안에 있는 플레이어를 강화하며, 태양핵 자체는 공격하지 않는다.
- 기존 공격, 회피, 일출, 시간 현상(역행) 시스템은 그대로 유지한다.
- 특성과 유물은 기존 획득 구조를 사용한다: 스테이지 클리어 시 특성 선택, 보스 처치·상점에서 유물 획득.
- 기존 역행 권능과 함께 쓰는 **별도 능력**이다.

## 2. 기본 능력: 태양핵

| 항목 | 내용 |
|---|---|
| 플레이어 행동 | 전용 버튼을 눌러 소환 |
| 발동 조건 | 행동 가능 상태, 설치된 태양핵 수 < 최대 개수, 쿨타임 종료 |
| 결과 | 바라보는 방향 2m 앞에 고정 설치. 유지시간 동안 범위 안의 플레이어를 강화 |
| 실패 처리 | 2m 앞이 막혀 있으면 플레이어 위치에 소환. 그 위치도 유효하지 않으면 **소환 실패, 쿨타임 소모 없음** |
| 조절 수치 | 소환 거리, 최대 개수, 효과 반경, 유지시간, 쿨타임, 버프 3종 |

**규칙 [확정]**
- 최대 개수는 기본 1개다.
- 효과 반경 3m, 유지시간 6초다.
- 쿨타임 6초는 **소멸 후부터** 센다.
- 범위 안에 있는 플레이어는 이동 속도 +20%, 공격력 +15%, 방어력 +10%를 받는다. 방어력 계산식은 미결 M1.
- 범위를 벗어나면 강화 효과가 즉시 사라진다.
- 태양핵 강화 효과끼리는 중첩되지 않는다. 여러 범위가 겹쳐도 한 번만 적용된다.
- 태양핵 자체는 공격하지 않는다.
- 역행 중에는 유지시간만 멈추고, 설치 상태는 되감지 않는다. (2026-10-19 사용자 결정)
- 소환 키는 **F**다. (2026-10-19 탑다운 전환으로 WASD 이동과 겹쳐 D → F로 변경. 역행은 우클릭)

| 조절 수치 | 기본값 |
|---|---|
| 소환 거리 | 2m |
| 최대 개수 | 1 |
| 효과 반경 | 3m |
| 유지시간 | 6초 |
| 쿨타임(소멸 후) | 6초 |
| 이동 속도 보너스 | +20% |
| 공격력 보너스 | +15% |
| 방어력 보너스 | +10% |

## 3. 전용 특성 5종 [확정]

특성은 기존 특성 선택 화면의 통합 풀에 들어간다. 희귀도와 레벨 구조는 미결 M6·M7.

### T1. 태양풍 (일반)
| 항목 | 내용 |
|---|---|
| 결과 | 태양핵 이동 속도 보너스 +10%p (기본 20% → 30%) |
| 조절 수치 | 추가 이동 속도 보너스(10%p) |

### T2. 광역 확장 (일반)
| 항목 | 내용 |
|---|---|
| 결과 | 태양핵 효과 반경 +40% (기본 3m → 4.2m) |
| 조절 수치 | 반경 증가율(40%) |

### T3. 잔존하는 태양 (일반)
| 항목 | 내용 |
|---|---|
| 결과 | 태양핵 유지시간 +3초 (기본 6초 → 9초) |
| 조절 수치 | 추가 유지시간(3초) |

### T4. 유랑하는 태양 (희귀)
| 항목 | 내용 |
|---|---|
| 결과 | 태양핵을 **이동 동반형**으로 바꾼다. 태양핵이 플레이어를 따라 이동한다 |
| 수치 | 기본 반경 2m, 이동 속도 +15%, 공격력 +10%, 방어력 +7% |
| 유지 규칙 | 유지시간과 쿨타임은 기본 규칙(6초 / 소멸 후 6초) 그대로 |
| 조합 | 다른 태양핵 강화 특성과 함께 쓸 수 있다. 계산 방식은 미결 M8 |
| 조절 수치 | 동반형 반경(2m), 이동 속도(15%), 공격력(10%), 방어력(7%) |

### T5. 지연 방출 (희귀)
| 항목 | 내용 |
|---|---|
| 발동 조건 | 태양핵 소멸 |
| 결과 | 소멸 시점에 범위 안에 있는 적에게 2초간 이동 속도 −25% |
| 연계 | 기존 시간 현상 시스템과 연계한다. 연계 방식은 미결 M5 |
| 조절 수치 | 감속률(25%), 지속시간(2초) |

## 4. 전용 유물 2종 [확정]

유물은 기존 유물 풀(보스 보상, 상점)에 들어간다. 둘 다 희귀 유물이며, 상점에서는 희귀 유물 가격을 적용한다.

### R1. 부서진 해시계 (희귀)
| 항목 | 내용 |
|---|---|
| 발동 조건 | 태양핵 소멸 |
| 결과 | 소멸 위치에 **잔광 영역**을 3초간 만든다 |
| 잔광 영역 효과 | 태양핵의 공격력·방어력 보너스를 **50% 효율**로 유지한다. 이동 속도 보너스는 적용하지 않는다 |
| 실패 처리 | 해당 없음 |
| 조절 수치 | 잔광 유지시간(3초), 효율(50%) |

### R2. 태양의 성좌 (희귀)
| 항목 | 내용 |
|---|---|
| 발동 조건 | 플레이어가 태양핵 범위 **밖에서 안으로** 진입 |
| 결과 | 일출 게이지 5% 충전 |
| 제한 | 태양핵 하나당 최대 2회, 발동 간 최소 간격 2초 |
| 실패 처리 | 일출 게이지가 없으면 작동하지 않음 (미결 M2) |
| 조절 수치 | 충전량(5%), 태양핵당 최대 횟수(2), 최소 간격(2초) |

## 5. 기존 시스템과의 상호작용

| 시스템 | 규칙 | 상태 |
|---|---|---|
| 공격 | 공격력 보너스는 기존 피해 증가% 합에 더한다 (`공격력 × (1 + 피해 증가% 합) × 치명타`, CombatDecisions 2장) | 구현됨 |
| 방어 | 받는 피해 감소% 합에 더한다 (`적 피해 × (1 − 감소% 합)`, CombatDecisions 2장) | 임시 구현, M1 |
| 회피(대시) | 변경 없음. 대시 무적과 태양핵 강화는 함께 적용된다 | [확정] |
| 역행 | 역행 중 유지시간 정지, 되감지 않음 | [확정] |
| 이동 속도 | 시작 능력 등 다른 이동 보너스와 합산 (예: +20% + +20% = 1.4배) | 구현됨 |
| 특성·유물 획득 | 기존 추첨·선택·상점 구조 사용 | [확정] |
| 일출 | 기존 시스템 유지. 단, 시험판 A에서는 일출이 본편으로 제외됨(VerticalSliceA 3장) | M2 |
| 방 이동 | 설치된 태양핵을 제거하고 쿨타임 시작 (현재 구현) | M10 |
| 사망·재탄생 | 태양핵 제거, 쿨타임 초기화, 특성·유물 초기화(기존 규칙) | 구현됨 |

## 7. 테스트 기준

| # | 확인 내용 | 통과 기준 |
|---|---|---|
| 1 | 소환 위치 | 바라보는 방향 2m 앞에 설치된다. 벽에 막히면 플레이어 위치에 설치된다 |
| 2 | 소환 실패 | 두 위치가 모두 무효이면 설치되지 않고 쿨타임이 그대로다 |
| 3 | 최대 개수 | 설치된 상태에서 다시 누르면 추가로 설치되지 않는다 |
| 4 | 유지·쿨타임 | 6초 후 소멸하고, 그 뒤 6초 동안 소환할 수 없다 |
| 5 | 강화 적용·해제 | 범위 안에서는 이동·공격·방어 보너스가 적용되고, 범위를 벗어나면 즉시 해제된다 |
| 6 | 비중첩 | 범위가 겹쳐도 보너스가 한 번만 적용된다 |
| 7 | 비공격 | 태양핵에 닿은 적이 피해를 받지 않는다 |
| 8 | 회피 | 범위 안에서 대시해도 무적과 강화가 모두 정상 동작한다 |
| 9 | 역행 | 역행 중에는 유지시간 표시가 멈추고, 역행 후 이어서 줄어든다 |
| 10 | 재탄생 | 사망 후 태양핵과 쿨타임이 초기화된다 |
| 11 | 특성 T1~T3 | 반영 후 수치가 30% / 4.2m / 9초가 된다 |
| 12 | 특성 T4 | 태양핵이 플레이어를 따라오고 2m·15%·10%·7%가 적용된다 |
| 13 | 특성 T5 | 소멸 시 범위 안의 적이 2초간 25% 느려진다 |
| 14 | 유물 R1 | 소멸 위치에 3초간 잔광이 생기고, 공격·방어 보너스가 절반이며, 이동 보너스는 없다 |
| 15 | 유물 R2 | 진입 시 게이지 5% 충전. 태양핵당 2회, 2초 간격 제한을 지킨다 |
| 16 | 획득 | 특성은 선택 화면에, 유물은 보스 보상과 상점에 나온다 |

## 8. 미결 사항 (구현 전 확인)

| # | 우선 | 항목 | 확인할 내용 |
|---|---|---|---|
| M1 | **P0** | 방어력 계산식 | 코드와 문서에 **방어력 스탯이 없다.** 피해 감소% 합만 있다(CombatDecisions 2장, 상한 없음). "방어력 +10%"를 ① 받는 피해 −10%(현재 임시 구현)로 볼지, ② 받는 피해 ÷ 1.1(약 −9.1%)로 볼지 결정해야 한다. 유랑하는 태양의 +7%와 잔광 50% 효율도 같은 식을 따른다 |
| M2 | **P0** | 일출 게이지 | 코드에 **일출 게이지가 없다.** 시간은 06:00에 다음 날 18:00으로 넘어가는 처리만 있다. VerticalSliceA 3장은 일출을 본편으로 제외했다[확정]. 태양의 성좌를 시험판에 넣을지, 일출 구현 전까지 비활성으로 둘지 정해야 한다 |
| M3 | **P0** | 쌍성 미구현 | "쌍성"은 코드와 기존 문서 어디에도 정의가 없다. 무엇인지(최대 개수 증가 수단인지 등), 이번 범위인지 확인해야 한다. 현재는 최대 개수를 늘리는 수단이 없어 기본 1개로 고정이다 |
| M4 | P1 | 잔광 중첩 | ① 잔광 영역과 태양핵 범위가 겹칠 때 둘 중 큰 값만 적용하는가 ② 잔광 영역이 여러 개 겹칠 때의 처리 ③ 잔광 영역 반경(태양핵 반경과 같은가) ④ 시작 능력 "잔광"(temp_b)과 이름이 겹친다 |
| M5 | P1 | 지연 면역·연계 | ① 감속 중 다시 맞으면 갱신, 중첩, 면역 중 무엇인가 ② 보스에게 적용하는가 (기존 정지장은 일반 적만) ③ "시간 현상 연계"의 구체 내용 (역행 중 감속 시간도 멈추는가 등) |
| M6 | P1 | 특성 희귀도 | 기존 특성 정의에는 희귀도가 없고, 추첨은 후보별 동일 확률이다(CombatDecisions 9장). 일반·희귀의 등장 확률 차이가 필요한가 |
| M7 | P1 | 특성 레벨 | 기존 특성은 Lv.1~3 수치를 가진다. 태양핵 특성 5종은 수치가 1단계뿐이다. 단일 레벨로 할지, Lv.2·3 수치를 정할지 |
| M8 | P1 | 특성 조합 계산 | 유랑하는 태양과 함께 쓸 때: 태양풍이 15% + 10%p = 25%가 되는가, 광역 확장이 2m × 1.4 = 2.8m가 되는가 |
| M9 | P1 | 소환 위치 판정 | "막힘"(벽·지형 겹침 등)과 "유효하지 않음"(방 밖, 지형 내부 등)의 정의. |
| M10 | P2 | 방 이동 | 방을 옮길 때 태양핵을 제거하는 것(현재 구현)을 "소멸"로 보고 지연 방출·해시계를 발동시키는가 |
| M11 | P2 | 성좌 진입 정의 | 소환 순간 이미 범위 안에 있으면 진입으로 치는가. 유랑하는 태양은 항상 범위 안에 있으므로 발동 조건이 성립하지 않는다 |
| M12 | P2 | 쿨타임과 역행 | 역행 중 쿨타임도 멈추는가 (현재 구현은 계속 흐름) |
| M13 | P2 | 시험판 범위 | 시험판 A는 "권능 역행 고정"이다(VerticalSliceA). 태양핵을 A에 포함하는지 확인 |
