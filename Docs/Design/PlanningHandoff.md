# Unity 시간 테마 로그라이크 — 기획 인수인계 요약

## 0. 프로젝트 및 작업 원칙

- 엔진: Unity 6000.3.12f1 (6.3 LTS), C#
- 장르: 2D 실시간 액션 로그라이크, 보스전 중심
- 목적: 1인 개발 취업용 포트폴리오
- 개발 방식: ChatGPT가 기획 및 Claude Code 작업 프롬프트 작성, Claude Code가 구현
- 핵심 목표: 시간 권능을 단순 스킬이 아닌 전투 규칙으로 구현
- 현재 진행 단계: 3단계, 1차 시험판 범위 확정 완료

응답 규칙:
- 확정 / 제안 / 미결을 구분한다.
- 과도한 칭찬 없이 기획의 약점을 평가한다.
- 확정되지 않은 내용을 임의로 확정하지 않는다.
- 새로운 시스템보다 시험판 세부 규칙과 문서화에 집중한다.

## 1. 세계관 및 전체 진행 구조 [확정]

- 태양신은 시간의 순환을 유지하는 존재였다.
- 달의 12시종은 영원한 것을 절대적 가치로 여기며 반역을 일으켰다.
- 시종들은 영원한 밤을 만들기 위해 태양신을 몰락시켰다.
- 달은 비교적 수동적인 존재이며, 시종들은 달이 영원히 존재하기를 바란다.
- 주인공은 태양신의 힘을 되찾기 위해 시종들과 싸운다.
- 사망 후 다시 시작하는 현상의 명칭은 순환.
- 사망하면 다음 순환의 18:00부터 다시 시작한다.
- 영구 성장과 해금은 유지된다.
- 해당 판의 특성, 유물, 상점 재화는 초기화된다.

전체 게임:
- 4장 × 3보스 = 총 12보스
- 보스당 일반 스테이지 2개 + 보스 스테이지 1개
- 전체 36개 스테이지
- 시간은 18:00부터 다음 날 06:00까지 진행
- 1장: 탄생
- 2장: 존재
- 3장: 쇠퇴
- 4장: 종언
- 주요 보스 권능: 역행, 감속, 공유, 침식, 갱신, 분기, 예지, 인과 역전 등
- 6번째 보스인 자정 보스 처치 후 일출이 다가오는 느낌의 컷신 배치
- 일출 실제 해금 시점과 효과는 미결

## 2. 플레이어 시간 권능 [핵심 방향 확정]

순환 시작 시 역행, 정지, 가속 중 하나를 선택한다.
처음부터 세 권능 모두 선택 가능하다.

### 과거 — 시간 역행

- 전장 전체를 일정 시간 전 상태로 즉시 복원한다.
- 플레이어와 적의 위치, 체력, 공격 진행 상황 등을 복원한다.
- 플레이어가 받은 피해를 취소할 수 있다.
- 적에게 준 피해도 취소될 수 있다.
- 보스 공격 결정 이후로 돌아가면 기존 공격을 이어간다.
- 결정 이전으로 돌아가면 공격을 다시 선택할 수 있다.
- 일반 적은 역행 후 이전에 사용한 공격을 반복한다.
- 사망 확정, 보스 처치 확정, 권능 비용과 쿨타임은 복원 예외로 둔다.
- 예외 처리의 정확한 시점과 경계 조건은 미결

임시 수치:
- 역행 거리: 2초
- 쿨타임: 20초

### 현재 — 시간 정지

- 플레이어를 제외한 전장의 시간을 정지한다.
- 플레이어는 정지 중 이동과 공격 가능
- 정지 중 발생한 피해는 종료 시 적용

임시 수치:
- 지속 시간: 2초
- 쿨타임: 25초

### 미래 — 시간 가속

- 플레이어의 시간만 상대적으로 빠르게 흐른다.
- 이동, 공격, 회피 등의 행동 가속

임시 수치:
- 가속 배율: 1.5배
- 지속 시간: 4초
- 쿨타임: 18초

## 3. 특성 시스템

공통 규칙 [확정]:
- 동일 특성 반복 선택 시 Lv.1 → Lv.2 → Lv.3
- 일반 스테이지 클리어 시 통합 특성 풀에서 3개 제시, 1개 선택
- 통합 풀은 선택한 권능 전용 특성과 공용 특성으로 구성
- 일반 스테이지에서는 후보별 동일 추첨 확률
- 일반 스테이지에서도 핵심 특성 Lv.3 완성 가능
- 보스 클리어 시 선택한 권능 전용 특성 3개 중 1개 선택
- 보스 보상은 일반 특성 선택과 중복 지급하지 않음
- 전체 기본 특성 선택 기회 36회
  - 일반 스테이지 24회
  - 보스 스테이지 12회
- 최대 레벨 특성 제외 및 후보 중복 규칙 미결

### 역행 전용 특성 4종

1. 잃어버린 찰나
   - 피해 이전으로 역행하면 보호막 획득

2. 되찾은 일격
   - 역행으로 취소된 공격 피해 일부를 다음 공격에 보존

3. 반복되는 운명
   - 다시 경험하는 보스 공격의 위험 범위를 더 일찍 표시

4. 과거의 잔상
   - 역행으로 취소된 공격을 잔상이 재현

### 정지 전용 특성 4종

1. 정지된 상처
   - 정지 중 축적한 피해를 종료 시 증폭

2. 멈춘 칼날
   - 정지 중 공격 궤적을 남겨 종료 시 추가 공격

3. 빼앗은 순간
   - 적 공격 직전 정지에 성공하면 공격 강화

4. 정지의 균열
   - 적 근처에서 정지 종료 시 공격 속도 증가

### 가속 전용 특성 4종

1. 압축된 연격
   - 가속 중 연속 적중하면 추가 타격

2. 앞선 발걸음
   - 가속 중 회피 및 공격 연계 강화

3. 미래의 대가
   - 가속 중 적중 횟수에 따라 종료 후 공격 강화

4. 시간 과부하
   - 가속 지속 시간을 소모해 공격 피해 강화

### 공용 특성 12종 [임시 설계]

공격:
1. 날카로운 검격: 공격 피해 +8% / +16% / +25%
2. 급소 포착: 치명타 확률 +5% / +10% / +15%
3. 신속한 연격: 공격 속도 +8% / +16% / +25%
4. 마무리 일격: HP 30% 이하 적 피해 +10% / +20% / +35%

생존:
5. 강인한 육체: 최대 HP +10 / +20 / +35
6. 굳건한 의지: 받는 피해 -5% / -10% / -15%
7. 생명의 장막: 전투 시작 보호막 10 / 20 / 35
8. 불굴의 회복: 전투당 첫 피격 후 HP 5 / 10 / 15 회복

자원 운용:
9. 시간 절약: 권능 쿨타임 -5% / -10% / -15%
10. 시간 축적: 권능 사용 가능 상태에서 대기하면 다음 권능 효과 강화, 최대 +5% / +10% / +15%
11. 시간 환급: 권능 사용 후 첫 공격 적중 시 쿨타임 1 / 1.5 / 2초 감소
12. 시간의 여유: 권능 사용 후 2 / 3 / 4초간 회피 쿨타임 -20%

공용 특성 이름과 수치는 임시이며 전투 규칙과의 충돌 검토 필요.

## 4. 유물 시스템

구조 [확정]:
- 기존 임시 유물 18종 + 신규 해금용 6종 = 24종
- 신규 유물 중 2종은 일출 관련
- 보스 처치 시 무작위 유물 1개 확정 지급
- 동일 유물 중복 획득 불가
- 유물 풀 소진 시 유물 대신 특성 선택 기회 제공
- 권능 전용 유물은 해당 권능 선택 시에만 등장
- 영구 성장 해금 유물은 보상 풀에 자동 추가
- 유물 목표 가치는 평균 특성 선택 1회 대비 약 120%
- 실제 밸런스는 플레이테스트에서 검증

권능 전용:

3. 미래의 태엽: 가속 중 3회 적중마다 지속 시간 +0.4초, 최대 +1.2초

공용 전투:
4. 균열의 회중시계: 회피 성공 후 3초 내 다음 공격 피해 +35%
5. 태양의 파편: 동일 적 4회 연속 적중 시 추가 피해 25
6. 낡은 생명시계: HP 30% 이하에서 피격 피해 50% 감소, 전투당 1회
7. 순환의 톱니: 일반 적 처치 시 HP 5 회복, 보스 8회 적중마다 HP 5 회복
8. 철의 태엽: 최대 HP +20
9. 부서진 검침: 기본 공격 피해 +15%
10. 수호자의 시곗바늘: 전투 시작 보호막 20

일시 강화:
11. 찰나의 축복: 적 처치 시 공격 속도 +20%, 5초
12. 붉은 초침: 치명타 발생 시 기본 공격 피해 +25%, 4초
13. 달빛의 파편: 회피 성공 시 받는 피해 -20%, 3초
14. 마지막 모래알: HP 40% 이하로 내려갈 때 이동 속도 +30%, 5초, 전투당 1회

자금:
15. 황금 톱니: 전투 재화 +25%
16. 상인의 낡은 장부: 상점 가격 -15%
17. 행운의 동전: 전투 보상 재화에 25% 확률로 +50%
18. 황혼의 금고: 즉시 120G, 이후 보스 처치 시 30G 추가

### 영구 성장 해금용 유물 6종 [수치 임시]

19. 인과의 고리: 권능 사용 후 첫 적중 공격 추가 피해 30%
20. 깨진 운명의 저울: HP 50% 이상 공격 피해 +12%, 미만 받는 피해 -12%
21. 불멸의 초침: 전투당 1회 치명적인 피해를 HP 1로 버티고 2초 무적
22. 시간의 수확자: 보스 6회 적중마다 권능 쿨타임 1초 감소
23. 여명의 성배: 일출 발동 시 최대 HP 15% 회복
24. 태양의 왕관: 일출 종료 후 5초간 공격 피해 +25%

아직 확정 아님.

## 5. 상점·재화·포션

상점 구조 [확정]:
- 스테이지의 숨겨진 시간의 통로로 진입
- 통로 너머 시간이 정지된 공간에서 거래
- 상점은 분기당 1회, 전체 4회 등장
- 포션과 유물만 판매
- 특성은 판매하지 않음
- 통로 발견 방식과 놓쳤을 때 처리 미결

경제 [임시]:
- 일반 클리어: 50G
- 보스 처치: 100G
- 포션: 60G
- 일반 유물: 180G
- 희귀 유물: 240G
- 전체 기본 획득 재화: 2,400G

포션:
- 체력 회복 포션 1종
- 전투 중 사용 가능
- 회복량: 임시 HP 40
- 최대 보유: 임시 3개
- 쿨타임: 임시 10초
- 포션이 없거나 HP가 최대면 사용 불가

## 6. 영구 성장 — 순환

구조 [확정]:
- 사망 후에도 영구 성장 유지
- 재화 임시 명칭: 기억 조각
- 기억 조각 및 구매 단계 유지
- G와 별도 관리
- 누적 투자량으로 성장 단계 개방
- 열린 단계 내 자유 투자
- 해금 특성/유물은 이후 보상 풀에 자동 추가
- 세 권능은 처음부터 사용 가능
- 권능 기본 성능도 영구 성장으로 강화 가능

단계:
1. 희미한 기억
   - 처음부터 개방
   - 최대 HP, 공격력, 포션 회복 효율

2. 깨어나는 시간
   - 누적 투자 100조각부터 개방 (임시)
   - 권능 기초 스탯 및 쿨타임 강화

3. 되찾은 가능성
   - 누적 투자 250조각부터 개방 (임시)
   - 신규 특성/유물/무기 해금

4. 태양의 기억
   - 일출 관련 성장
   - 세부 규칙 미결

권능 기초 강화 [임시]:
- 역행 거리: 2.0초 → 최대 2.6초
- 역행 쿨타임: 20초 → 최대 18초
- 정지 지속: 2.0초 → 최대 2.6초
- 정지 쿨타임: 25초 → 최대 22초
- 가속 배율: 1.5배 → 최대 1.8배
- 가속 지속: 4.0초 → 최대 4.6초

영구 성장 최대 투자 목표 [임시]:
- 전체 1,500 기억 조각
- 기초 능력: 300
- 권능 강화: 600
- 신규 유물 해금: 300
- 활/망치 해금: 200
- 일출 성장 예비: 100

기억 조각 획득 [임시]:
- 보스 처치: 10개
- 각 장 마지막 보스: 추가 20개
- 12보스 완주 시 총 200개
- 사망 후에도 유지

## 7. 무기 시스템 [확정]

- 전체 무기: 검/활/망치
- 검은 처음부터 사용 가능
- 활/망치는 영구 성장에서 해금
- 순환 시작 시 해금한 무기 중 하나 선택
- 해당 판 중 무기 교체 불가
- 권능과 무기는 자유롭게 조합

무기 방향:
- 검: 균형 잡힌 근접
- 활: 원거리
- 망치: 느리고 강한 근접

무기별 세부 수치는 미결.

## 8. 일출 [일부 확정]

- 태양신의 힘을 잠시 불러오는 능력
- 일몰은 도입하지 않음
- 별도 버튼으로 즉시 발동하는 방향
- 이동/공격 방식이 달라지는 새로운 존재 방식 목표
- 6번째 보스 처치 후 일출 암시 컷신
- 효과/수치/해금 시점 미결

## 9. 시험판 개발 범위 [확정]
