- 확정 / 제안 / 미결을 구분한다.
- 과도한 칭찬 없이 기획의 약점을 평가한다.
- 확정되지 않은 내용을 임의로 확정하지 않는다.
- 새로운 시스템보다 시험판 세부 규칙과 문서화에 집중한다.

## 2. 세계관과 순환 **[확정]**

### 세계관
- 태양신은 시간의 순환을 유지하는 존재였다.
- 달의 12시종은 영원한 것을 절대적 가치로 여기며 반역을 일으켰다.
- 시종들은 영원한 밤을 만들기 위해 태양신을 몰락시켰다.
- 달은 비교적 수동적인 존재이며, 시종들은 달이 영원히 존재하기를 바란다.
- 주인공은 몰락한 태양신 **본인**이며, 빼앗긴 힘을 되찾기 위해 시종들과 싸운다. (2026-10-17 사용자 확정)

### 순환 (사망 후 재시작)
- 사망 후 다시 시작하는 현상의 명칭은 **순환**.
- 사망하면 다음 순환의 **18:00**부터 다시 시작한다.
- 유지: 영구 성장, 해금
- 초기화: 해당 판의 특성, 유물, 상점 재화(G)

## 4. 플레이어 시간 권능 **[핵심 방향 확정]**

- 순환 시작 시 역행 / 정지 / 가속 중 하나를 선택한다.
- 처음부터 세 권능 모두 선택 가능하다.
- 권능 기본 성능은 영구 성장으로 강화 가능 (9장 참조).

### 4-1. 과거 — 시간 역행
- 전장 전체를 일정 시간 전 상태로 즉시 복원한다.
- 플레이어와 적의 위치, 체력, 공격 진행 상황 등을 복원한다.
- 플레이어가 받은 피해를 취소할 수 있다.
- 적에게 준 피해도 취소될 수 있다.
- 보스 공격 결정 **이후**로 돌아가면 기존 공격을 이어간다.
- 결정 **이전**으로 돌아가면 공격을 다시 선택할 수 있다.
- 일반 적은 역행 후 이전에 사용한 공격을 반복한다.
- 복원 예외: 사망 확정, 보스 처치 확정, 권능 비용, 쿨타임
- 예외 처리의 정확한 시점과 경계 조건: **[미결]**

| 수치 | 값 | 상태 |
|---|---|---|
| 역행 거리 | 2초 | [임시] |
| 쿨타임 | 20초 | [임시] |

### 4-2. 현재 — 시간 정지
- 플레이어를 제외한 전장의 시간을 정지한다.
- 플레이어는 정지 중 이동과 공격 가능.
- 정지 중 발생한 피해는 종료 시 적용.

| 수치 | 값 | 상태 |
|---|---|---|
| 지속 시간 | 2초 | [임시] |
| 쿨타임 | 25초 | [임시] |

### 4-3. 미래 — 시간 가속
- 플레이어의 시간만 상대적으로 빠르게 흐른다.
- 이동, 공격, 회피 등의 행동 가속.

| 수치 | 값 | 상태 |
|---|---|---|
| 가속 배율 | 1.5배 | [임시] |
| 지속 시간 | 4초 | [임시] |
| 쿨타임 | 18초 | [임시] |

## 6. 특성 전체 목록 (24종)

### 6-1. 공통 규칙 **[확정]**
- 동일 특성 반복 선택 시 Lv.1 → Lv.2 → Lv.3
- 일반 스테이지 클리어 시 통합 특성 풀에서 3개 제시, 1개 선택
- 통합 풀 = 선택한 권능 전용 특성 + 공용 특성
- 일반 스테이지에서는 후보별 동일 추첨 확률
- 일반 스테이지에서도 핵심 특성 Lv.3 완성 가능
- 보스 클리어 시 선택한 권능 전용 특성 3개 중 1개 선택
- 보스 보상은 일반 특성 선택과 중복 지급하지 않음
- 전체 기본 특성 선택 기회 36회 (일반 24, 보스 12)
- 최대 레벨 특성 제외 및 후보 중복 규칙: **[미결]**

## 7. 유물 전체 목록 (24종)

### 7-1. 구조 **[확정]**
- 기존 임시 유물 18종 + 신규 해금용 6종 = 24종
- 신규 유물 중 2종은 일출 관련 (#23, #24)
- 보스 처치 시 무작위 유물 1개 확정 지급
- 동일 유물 중복 획득 불가
- 유물 풀 소진 시 유물 대신 특성 선택 기회 제공
- 권능 전용 유물은 해당 권능 선택 시에만 등장
- 영구 성장 해금 유물은 보상 풀에 자동 추가
- 유물 목표 가치: 평균 특성 선택 1회 대비 약 120%
- 실제 밸런스는 플레이테스트에서 검증

## 16. 보상 순간 설계 **[확정]** (2026-10-21 사용자 결정)

원칙: 보상 순간을 억지로 만들지 않는다. 플레이어가 **스스로 해냈다고 느끼는 순간**을 설계하고, 연출은 그 순간을 키우는 데만 쓴다.

### 16-1. 권능 전용 특성 Lv.3 형태 변화
- 권능 전용 특성 12종(6-2~6-4)은 Lv.3에서 수치만 오르지 않고 **효과의 모양이 바뀐다.** Lv.3 도달이 빌드 완성 신호가 된다.
- 공용 특성 12종(6-5)은 현행대로 수치만 오른다.
- 예: 과거의 잔상 Lv.3 → 잔상이 2개로 늘어남
- 12종별 Lv.3 효과: **[미결]**

### 16-2. 일출 해금 시점
- 6번째(자정) 보스 처치 컷신 **직후** 일출이 해금된다. 후반 6보스는 일출을 쓰며 싸우고, 06:00 엔딩으로 이어진다.
- 순환마다 자정 보스를 처치해야 그 판에서 일출 사용 가능. 첫 해금만 전체 컷신, 이후 순환은 짧은 연출: **[제안]**
- 효과 / 수치: **[미결]** (11장)

### 16-3. 기억 아카이브
- 순환이 끝날 때(사망 또는 완주)마다 세계관 **기록** 하나가 열린다. 사망도 기대할 거리가 되게 하는 장치.
- 열린 기록은 아카이브 메뉴에서 다시 볼 수 있다.
- 기록 내용 예: 12시종의 기록, 태양신의 기억, 보스 처치 후 대사
- 영구 성장 재화 "기억 조각"과 구분하기 위해 아카이브 항목은 "기록"으로 부른다.
- 해금 조건(사망 횟수 / 처치 보스 / 도달 시각), 기록 개수: **[미결]**

### 16-4. 시간 진행 연출
- 18:00 → 06:00 흐름을 화면과 소리로 보여준다. 보스 1명 = 1시간 (12보스 = 12시간, 6번째 보스 처치 = 자정).
- 보스 처치 시: 시계 바늘이 다음 시각으로 넘어감 + **시계 딸깍 소리** + 하늘색 한 단계 변화
- 하늘색: 자정까지 점점 어두워지고, 자정 이후 점점 밝아짐
- 장 마지막 보스(3·6·9·12번째) 처치 시 더 큰 연출. 예: 자정에 종 12번 (달의 12시종과 연결)
- 12번째 보스(05시) 처치 시 시계는 06시 직전에 멈춘다. 다음 시각으로 넘어가지 않는 유일한 예외다. 플레이어가 동쪽 끝에서 권능을 발동하면 06:00 → 승리 확정, 일출 엔딩 (2026-10-26, `WorldLevelStructure.md` 5·10절)
- 하늘색 단계, 종소리 외 장 전환 연출 세부: **[미결]**
