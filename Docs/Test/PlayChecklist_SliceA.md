# 시험판 A 플레이 체크리스트

조작: WASD 이동 · 마우스 조준 · 좌클릭 공격 · Space 회피 · 우클릭 역행 · Q 포션 · E 통로 진입 · F10 역행 위치 미리보기 · F11 디버그(G +100, 기억 조각 +10)

## ① 진행 (일반 2 + 보스 1)
- [ ] 시작하면 선택 화면 없이 1스테이지. HUD 둘째 줄에 `0G  기억 조각 N  포션[Q] 1  역행[RMB] 준비`
- [ ] 적 전멸 → 출구에 닿으면 특성 카드 3장, 상단 "+50G", 카드 배지 "신규 Lv.1"
- [ ] 카드를 고르면 2스테이지로 이동

## ② 특성 규칙
- [ ] 같은 특성을 다시 고르면 배지가 "Lv.1 → Lv.2"
- [ ] 한 번에 뜬 3장에 같은 특성이 겹치지 않음
- [ ] 보스 처치 후에는 "역행 전용" 카드만 나옴
- [ ] 오른쪽 아래 디버그 목록에 보유 특성과 레벨이 맞게 표시됨

## ③ 상점
- [ ] 2스테이지 적 전멸 후 **입구 뒤쪽 벽 앞**에 깜빡이는 통로가 생김
- [ ] 통로 안에서 E → 상점 열림. 포션 30G, 유물 80G / 100G
- [ ] G가 모자라면 "구매 불가"
- [ ] 나가기 → 통로가 사라짐. 통로에 들어가지 않고 출구로 가면 이번 판에서는 다시 열 수 없음

## ④ 보스와 역행
- [ ] 내려베기에 맞은 직후 우클릭 → 하단 줄 "취소 Slash 제외: 재선택 예정", 보스가 다른 공격을 고름
- [ ] 탄막·낙하에 맞은 직후 우클릭 → "이어감"
- [ ] 역행 후 쿨타임 20초 동안 우클릭 → "사용 불가: 쿨타임"
- [ ] 보스 처치 → 보상(유물 획득 + "기억 조각 +10") → 결과 화면 → "영구 성장으로" → 성장 화면

## ⑤ 역행 특성·유물 (F11로 G를 모아 상점에서 사거나 보상으로 얻기)
- [ ] 잃어버린 찰나: 맞고 역행하면 HUD에 "보호막 N"
- [ ] 시간 절약: 역행 쿨타임이 20초보다 짧게 시작
- [ ] 과거의 잔상: 적을 때리고 역행하면 같은 박자에 반투명 잔상 판정
- [ ] 철의 태엽: 최대 HP +20

## ⑥ 사망과 순환
- [ ] 일부러 죽으면 2초 뒤 성장 화면. 기억 조각 유지
- [ ] "다음 순환 시작" → 1스테이지. G 0, 특성·유물 없음, 포션 1개, 일차 +1
- [ ] 성장에서 "최대 HP" 구매 → 다음 판 최대 HP 110
- [ ] 플레이를 껐다 켜도 기억 조각·성장 레벨 유지 (`persistentDataPath/slice_a_save.json`)

## 알려진 한계 (코드 점검으로 확인)
- "반복되는 운명"은 탄막에 위험 범위 표시가 없어 효과가 보이지 않음 (내려베기·돌진·낙하에서만 확인 가능)
- HUD 시계는 보스 처치 전까지 18:00에 머무름 (1시간 전진은 보스 처치 때만)
- 상점·성장 화면은 임시 IMGUI
- 씬에 `GameFlow`가 직접 배치돼 있으면 거기 저장된 값이 코드 기본값보다 우선함 (미확인)

결함을 발견하면 재현 절차(어느 스테이지, 어떤 입력, 기대 결과 vs 실제 결과)를 함께 적어 주세요.

# 외부 플레이테스트 (M-1 검증)

위 ①~⑥은 개발자 기능 확인용이다. 이 장은 외부 플레이어로 시험판 A의 플레이 경험을 평가하는 절차다.
성공 기준과 합격선은 `Docs/SliceA/VerticalSliceA.md` 14장 (모두 **[제안/검증 전]**).

## 1. 선행 조건

- [ ] **dev 작업 필요 (미구현):** 테스트 빌드용 디버그 표시 일괄 끄기. 디버그 줄, F10/F11, 보스 상태 줄, 보상 디버그 목록을 끈다. 이 오브젝트들은 실행 중 자동 생성이라 Inspector에서 끈 값이 저장되지 않는다
- [ ] **dev 작업 필요 (미구현):** 아래 6장 이벤트 로그 기록
- [ ] 개발자 체크리스트 ①~⑥ 통과, 치명적 오류 없음
- [ ] 테스트용 PC, 키보드, 화면 녹화 도구

## 2. 참가자

- 5~10명. 액션 게임 숙련도가 섞이도록 모집한다 (사전 설문 P3 기준 낮음·중간·높음)
- 이 프로젝트를 처음 접하는 사람

## 3. 참가자마다 초기화

- [ ] 저장 파일 삭제: `Application.persistentDataPath/slice_a_save.json`
- [ ] 게임을 새로 실행 (기억 조각 0, 영구 성장 0 확인)
- [ ] 화면 녹화 시작

## 4. 세션 진행표 (1명당 약 45분)

| 순서 | 내용 | 시간 |
|---|---|---|
| 사전 설문 | P1~P3 | 2분 |
| 안내 | 조작키만 알려 준다. 역행 규칙(2초, 결정 전후 차이)은 **설명하지 않는다** | 1분 |
| 첫 플레이 | 첫 사망 또는 첫 클리어까지 (최대 15분, 넘으면 종료) | ~15분 |
| 설문 A | 조작·전투·역행·보상 | 5분 |
| 순환 이후 플레이 | 영구 성장 화면부터 자유 플레이 | 15분 |
| 설문 B | 역행·영구 성장·순환·재도전·종합 + 이해 문항 U1·U2 | 5분 |
| 인터뷰 | I1~I4 | 5분 |

안내 문구 예시:
> WASD 이동, 마우스로 조준, 좌클릭 공격, Space 회피, 우클릭 시간 역행, Q 포션, E 통로 들어가기. 플레이하면서 떠오르는 생각을 소리 내어 말해 주세요.

진행자 규칙:
- 플레이 중 도움·힌트를 주지 않는다. 막히면 "어떻게 하면 될 것 같아요?"까지만 묻는다
- 게임 규칙에 대한 질문에는 설문이 끝난 뒤 답한다
- 진행 불가 상황이면 관찰 기록지에 적고 재시작을 돕는다 (S1 치명적 오류로 기록)

## 7. 설문

척도: 1 전혀 아니다 · 2 아니다 · 3 보통 · 4 그렇다 · 5 매우 그렇다

### 사전 설문
- P1. 액션 게임이나 로그라이크를 얼마나 하나요? (안 함 / 가끔 / 자주)
- P2. 즐겨 한 비슷한 게임이 있다면? (자유)
- P3. 키보드로 하는 액션 게임 실력은? (1~5)

### 설문 A — 첫 플레이 직후
| # | 문항 | 지표 |
|---|---|---|
| A1 | 이동·조준·회피·공격이 원하는 대로 움직였다 | S2 |
| A2 | 내 공격이 맞았는지, 내가 맞았는지 알아보기 쉬웠다 | S2 |
| A3 | (보스에 도달한 경우) 보스 공격이 언제, 어디로 올지 미리 알아볼 수 있었다 | 참고 |
| A4 | 시간 역행(S)을 쓰는 것이 재미있었다 | S3 참고값 |
| A5 | 역행을 써야 할 때를 판단할 수 있었다 | S3 참고값 |
| A6 | 특성 카드 3장 중 고르는 것이 고민할 만했다 | S6 |
| A7 | 고른 특성의 효과를 전투에서 느꼈다 | S6 |

자유 의견
- A8. 가장 헷갈렸던 순간은 언제였나요?
- A9. 역행을 써서 상황이 좋아졌거나 나빠졌던 순간이 있었나요?

### 설문 B — 순환 이후 플레이 직후
| # | 문항 | 지표 |
|---|---|---|
| B1 | 시간 역행(S)을 쓰는 것이 재미있었다 | S3 |
| B2 | 역행을 써야 할 때를 판단할 수 있었다 | S3 |
| B3 | 영구 성장으로 강해진 것을 느꼈다 | S7 |
| B4 | 영구 성장 항목을 고르는 것이 의미 있었다 | S7 |
| B5 | 죽고 다시 시작하는 흐름(순환)이 자연스러웠다 | 참고 |
| B6 | (상점에 들어간 경우) 상점 이용이 도움이 되었다 | 참고 |
| B7 | 이 시험판은 전체적으로 재미있었다 | S9 |
| B8 | 지금 한 판 더 하고 싶다 (예 / 아니오) | S8 |

이해 문항 (보스에 도달한 참가자만, 객관식) — S4
- U1. 보스 공격에 맞은 뒤 역행했더니, **되돌아간 시점에 보스의 경고 범위가 이미 보이고 있었다.** 보스는 어떻게 할까요?
  - ① 같은 공격을 그대로 이어서 한다 ② 다른 공격을 새로 고른다 ③ 매번 무작위다 ④ 모르겠다
- U2. 보스 공격에 맞은 뒤 역행했더니, **되돌아간 시점에는 아직 경고 범위가 없었다.** 보스는 어떻게 할까요?
  - ① 같은 공격을 다시 한다 ② 방금 그 공격이 아닌 다른 공격을 고른다 ③ 매번 무작위다 ④ 모르겠다
- 정답: U1 ①, U2 ② (CombatDecisions 6·7장). 두 문항을 모두 맞혀야 "이해"로 센다

자유 의견
- B9. 다시 하고 싶었던 이유, 또는 그만두고 싶었던 순간은?
- B10. 딱 하나만 고칠 수 있다면 무엇을 고치겠어요?
