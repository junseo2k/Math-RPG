# 태양핵 수동 테스트 가이드

> 기준: `Docs/Design/SolarCoreSpec.md`, 설정 에셋 `Assets/Resources/SolarCoreSettings.asset`
> 작성일: 2026-10-19. 각 테스트의 체크박스에 결과를 기록한다(통과 `[x]`, 실패 시 옆에 메모).

---

## 0. 준비

### 0-1. 설정 에셋 열기
1. Unity 상단 메뉴 **Tools → 태양핵 설정 열기**. Project 창에서 `Assets/Resources/SolarCoreSettings` 가 선택된다(없으면 이때 자동 생성).
2. Inspector 구성

| 섹션 | 항목 | 기본값 |
|---|---|---|
| A. 태양핵 기본 능력 | Spawn Distance / Radius / Lifetime / Cooldown / Max Count | 2 / 3 / 6 / 6 / 1 |
| | Move Speed Bonus / Attack Bonus / Damage Reduction | 0.2 / 0.15 / 0.1 |
| B. 태양풍 | Extra Move Speed Bonus | 0.1 |
| B. 광역 확장 | Radius Bonus | 0.4 |
| B. 잔존하는 태양 | Extra Lifetime | 3 |
| B. 유랑하는 태양 | Radius / Move Speed Bonus / Attack Bonus / Damage Reduction | 2 / 0.15 / 0.1 / 0.07 |
| B. 지연 방출 | Duration / Slow Ratio | 2 / 0.25 |
| C. 부서진 해시계 | Duration / Efficiency | 3 / 0.5 |
| C. 태양의 성좌 | Charge Amount / Max Per Core / Min Interval | 0.05 / 2 / 2 |

- **퍼센트는 비율로 입력한다: 0.2 = 20%, 0.07 = 7%.** 항목에 마우스를 올리면 툴팁에 단위가 나온다.
- 저장: 값 변경 후 **Ctrl+S**(또는 File → Save Project). 에셋이라 씬 저장과 별개다.
- 플레이 모드 중 바꾼 값도 에셋에 그대로 남는다(ScriptableObject 특성). 실험 후 되돌릴 값은 기록해 둘 것.
- 플레이 중 변경은 태양핵 계산에 즉시 반영된다. 이미 설치된 태양핵의 반경·유지시간은 소환 시점 값이다.

### 0-2. 디버그 키와 표시
| 키 | 동작 |
|---|---|
| F | 태양핵 소환 |
| S | 역행 |
| F1 | 디버그 UI(스테이지 건너뛰기, 강제 사망) |
| F11 | G +100, 기억 조각 +10 |
| F12 | 태양핵 특성 5종 + 유물 2종 획득 |
| Shift+F12 | 태양핵 유물 2종만 획득 (특성 없이 해시계·성좌 시험) |

- 화면 왼쪽 아래 `태양핵 …` 줄: 상태 / 모드 / 반경 / 유지 / 이동·공격·방어 보너스 / 잔광 수 / 성좌 횟수.
- 화면 오른쪽 아래 `[보상 디버그]`: 보유 특성·유물 목록.
- 특성 하나만 시험하려면 F12 대신 방 클리어 후 **특성 선택 카드**에서 고른다. 카드가 안 나오면 F1 → 스테이지 건너뛰기로 보상 화면을 반복한다.
- 시험 사이에는 F1 → 강제 사망으로 특성·유물을 초기화한다.

## 1. 기본 능력

- [ ] **B1 소환 위치**
  - 목적: 바라보는 방향 2m 앞에 고정 설치
  - 조작: 평지에서 마우스로 오른쪽을 조준하고 F
  - 예상: 플레이어 오른쪽 2m에 노란 원(반경 3m) 생성, 움직여도 원은 제자리
  - 실패: 원이 플레이어 위치에 생기거나 따라온다
- [ ] **B2 막힘 처리**
  - 목적: 앞이 막히면 플레이어 위치로 대체
  - 조작: 벽에 붙어 벽 쪽을 조준하고 F
  - 예상: 원이 플레이어 위치에 생성
  - 실패: 벽 안/너머에 생성되거나 아무것도 생기지 않는다
- [ ] **B3 강화 적용·해제**
  - 목적: 범위 안에서만 3종 강화
  - 조작: 원 안팎을 오가며 ① 이동 ② 적 공격 ③ 적에게 피격
  - 예상: 원 안에서 표시 `범위 안`, 이동 1.2배, 공격 10→12, 받는 피해 −10%. 원 밖에서는 즉시 기본값
  - 실패: 밖에서도 강화가 남거나 안에서 적용되지 않는다
- [ ] **B4 유지·쿨타임**
  - 목적: 6초 유지, 소멸 후 6초 쿨타임
  - 조작: F 후 대기, 소멸 직후 F 연타
  - 예상: 6초 뒤 소멸, 표시 남은 초가 6.0부터 감소, 0 전에는 소환 안 됨
  - 실패: 시간이 다르거나 쿨타임 중 소환된다
- [ ] **B5 중복 소환 방지**
  - 조작: 원이 있는 동안 F
  - 예상: 두 번째 원이 생기지 않는다
- [ ] **B6 비공격**
  - 조작: 적을 원 안에 둔 채 대기
  - 예상: 적 HP 변화 없음
- [ ] **B7 설정 반영**
  - 목적: 설정 에셋 값이 실제 플레이에 반영
  - 조작: 설정 에셋 A의 Radius를 5, Lifetime을 3으로 바꾸고 F
  - 예상: 표시 `반경 5.0m 유지 3초`, 원이 커지고 3초 뒤 소멸. 확인 후 3 / 6으로 되돌리고 Ctrl+S
  - 실패: 값이 반영되지 않는다

## 2. 특성

> 단독 효과 확인은 보상 카드에서 해당 특성만 고른다. F12는 5종 동시 획득이다.

- [ ] **T1 태양풍**: 획득 후 표시 `이동 +30%`. 카드 문구 `+10%p`
- [ ] **T2 광역 확장**: 획득 후 `반경 4.2m`, 원이 커진다
- [ ] **T3 잔존하는 태양**: 획득 후 `유지 9초`, 9초 뒤 소멸
- [ ] **T4 유랑하는 태양**
  - 예상: 표시 `동반형 반경 2.0m 이동 +15% 공격 +10% 방어 +7%`, D를 누르면 원이 플레이어 위치에 생기고 따라다님. 6초 뒤 소멸, 6초 쿨타임
  - 실패: 원이 제자리에 남는다
- [ ] **T5 지연 방출**
  - 조작: 순찰 적이 원 안에 있을 때 소멸을 기다린다
  - 예상: 적이 2초간 느려진다(정지장과 달리 색 변화 없음). 보스에게는 적용 안 됨
  - 실패: 감속 없음, 2초 넘게 지속, 범위 밖 적까지 감속
- [ ] **T6 조합(F12)**
  - 예상: `동반형+지연 반경 2.8m 유지 9초 이동 +25% 공격 +10% 방어 +7%`
- [ ] **T7 단일 레벨·희귀 표시**
  - 예상: 획득한 태양핵 특성은 이후 카드에 다시 나오지 않음. 유랑·지연 카드에 `희귀 · 신규` 배지
- [ ] **T8 카드 문구 반영**
  - 조작: 설정 B 태양풍 0.1 → 0.2, 다음 보상 화면
  - 예상: 카드 문구 `+20%p`. 확인 후 0.1로 되돌림

## 3. 유물

- [ ] **R1 부서진 해시계 잔광**
  - 준비: Shift+F12 (설치형 유지)
  - 조작: 설치형 태양핵이 소멸할 때까지 대기 후 주황 영역 안에 선다
  - 예상: 소멸 위치에 주황 잔광 3초. 잔광 안: 공격 +7.5%(10→11), 받는 피해 −5%, 이동 보너스 없음. 표시 `잔광 1`
  - 실패: 잔광 없음, 이동 보너스 적용, 3초 넘게 남음
- [ ] **R2 잔광·태양핵 비중첩**
  - 조작: 잔광 위에 새 태양핵을 겹쳐 소환하고 겹친 곳에 선다
  - 예상: 태양핵 수치만 적용(합산 아님)
- [ ] **R3 태양의 성좌 발동**
  - 준비: Shift+F12 (유랑 없이 성좌 보유)
  - 조작: 원 밖에 서서 F(2m 앞 소환이므로 반경 3m 안일 수 있음 → 표시가 `성좌 0/2`인지 확인) → 원 밖으로 나갔다 들어오기를 1초 간격, 3초 간격으로 반복
  - 예상: 소환 순간 이미 안이면 증가 없음. 밖→안 진입마다 `성좌 1/2`, `2/2`. 2초 안에 재진입하면 증가 없음. `2/2` 이후 증가 없음. 새 태양핵을 소환하면 `0/2`부터 다시
  - 실패: 2회 초과, 2초 이내 재발동, 소환 직후 증가
- [ ] **R4 성좌 비활성(유랑)**
  - 조작: R3에 이어 `성좌 1/2` 이상 만든 뒤, 다음 보상 카드에서 유랑하는 태양 획득(또는 F12) → F
  - 예상: 표시 `성좌 비활성(유랑)`, 횟수 증가 없음. 오른쪽 아래 유물 목록에 성좌는 남아 있음. 이전에 발생한 충전은 그대로(취소 처리 없음)
- [ ] **R5 보상 등장**
  - 예상: 보스 보상·상점에 해시계는 나올 수 있고, 성좌는 나오지 않는다

## 4. 상점·보상 화면

- [ ] **S1 상점에서 시간 흐름**
  - 조작: 태양핵 설치 직후 상점 통로(E)로 입장, 6초 이상 머문 뒤 퇴장
  - 예상: 퇴장 시 태양핵이 이미 소멸, 쿨타임도 진행 중이거나 끝남
  - 실패: 상점 동안 시간이 멈춰 있다
- [ ] **S2 보상 선택 화면에서 시간 흐름**
  - 조작: 태양핵을 켠 채 방 클리어 → 카드 화면에서 6초 이상 대기
  - 예상: 카드 화면 동안 소멸(해시계 보유 시 잔광 생성, 지연 보유 시 감속 발동). 다음 방 진입 시 모두 제거

## 5. 초기화

- [ ] **I1 방 이동**
  - 조작: 태양핵 유지 중 출구로 이동
  - 예상: 원·잔광 제거, 지연 방출·잔광 발동 없음, 쿨타임 시작, 강화 해제
- [ ] **I2 사망·재탄생**
  - 조작: 원 안에서 F1 → 강제 사망 → 성장 화면 → 다음 순환
  - 예상: 원 없음, `[F] 준비`, 이동·공격·피해 기본값, 특성·유물 초기화
- [ ] **I3 클리어 후 다음 순환**: I2와 같은 결과
- [ ] **I4 역행**
  - 조작: 원 안에서 S
  - 예상: 역행 동안 유지시간·쿨타임 정지, 역행 후 이어짐. 역행 중 소환 불가
- [ ] **I5 잔류 확인**: I1~I3 직후 이동 속도·피해가 기본과 같은지(원 밖 대조)

## 6. 기존 기능 회귀

- [ ] **G1 공격**: 원 밖 공격 10, 치명타 15 그대로
- [ ] **G2 회피**: 대시 거리·무적·쿨타임 그대로. 원 안 대시도 정상
- [ ] **G3 회피 유물**: 균열의 회중시계(다음 공격 +35%), 달빛의 파편(받는 피해 −20%)이 원 안팎에서 정상
- [ ] **G4 정지장 대상 적**: 일반 적 피격·정지·사망·역행 부활 정상
- [ ] **G5 보스전**: 축적·유예·역행 보스 각 1회. 유예 피해는 원 안에서 −10% 적용
- [ ] **G6 보상 규칙**: 보스 첫 선택은 역행 전용 특성만, 이후 통합 풀. 기존 특성 Lv.1~3 진행 정상
