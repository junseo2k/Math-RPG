# 사운드 사양 (Sound Specification)

> 상위 문서: `Docs/GameDesignOverview.md`, `Docs/VerticalSliceSpec.md`, `Docs/Bosses/01_Accumulation.md`, `Docs/ArtSpecification.md`
> 표기: **[확정]** 사용자 확정 / **[미결]** 미정
> 이 문서는 확정된 규칙에 소리를 붙일 뿐, 새 게임 규칙이나 보스 패턴을 추가하지 않는다.

---

## 1. 전체 방향

### 1-1. 확정 [확정]
- 음악 스타일: **중세풍**. 이집트 신화는 스토리·서사에만 쓰고, 음악에는 이집트풍을 넣지 않는다.
- 제작 수단: **AI 생성 + 편집** (8장)

### 1-2. 기준 [확정]
| 항목 | 내용 |
|---|---|
| 악기 | 류트, 허디거디, 리코더·숌, 테이버(작은 북), 종, 성가풍 합창, 저음 드론 |
| 선법 | 도리안·프리지안·믹솔리디안 등 교회 선법 중심 |
| 태양신 측 | 따뜻한 현(류트)·관(리코더), 믹솔리디안처럼 밝은 선법. "흐름"은 앞으로 진행하는 리듬 |
| 달의 시종 측 | 성가풍 합창, 차가운 종, 지속되는 드론, 프리지안. "불변"은 같은 음형의 반복 |

**의도**: 흐름(태양신)과 불변(시종)의 대립을 리듬이 나아가는가, 제자리에서 반복되는가로 들려준다.

## 2. 음악

| 곡 | 장면 | 방향 [확정] | 반복 | 전환 조건 |
|---|---|---|---|---|
| `bgm_start` | 시작 지점·능력 선택 | 노을의 고요. 류트 아르페지오 + 낮은 드론 | O | 능력 선택 → `bgm_ch1` 교차 페이드 |
| `bgm_ch1` | 1장 일반 방 | 테이버 리듬 중심. 시각이 지날수록(19·20시) 층 추가 | O | 보스 방 진입 → `bgm_boss_accumulation` |
| `bgm_boss_accumulation` | 축적 보스전 | 같은 음형이 한 겹씩 쌓이는 구조. 방출 직전 정점, 탈진 때 잠시 비움 | O | 보스 처치 → `bgm_ch1` 복귀 |
| `bgm_clear` | 시험판 클리어 | 짧은 해방감, 밝은 종소리 | X | — |

- 시각에 따른 층 추가는 **[확정]**: 18시 기본 → 보스 처치마다 악기 1개 추가(시간 진행을 귀로도 느끼게).
- 사망 시 BGM은 페이드 아웃 후 재탄생과 함께 `bgm_start` 재시작.

## 3. 효과음

### 3-1. 목록과 우선순위
| 분류 | 효과음 | 길이 [확정] | 우선순위 |
|---|---|---|---|
| 위험 예고 | 방출 예고, 돌진 예비 | 패턴 예고 시간과 동일 | 1 (최우선) |
| 플레이어 | 피격, 사망 | 0.2초 / 0.4초 | 2 |
| 보스 패턴 | 축적 스택, 방출 충격파, 돌진, 탈진 | 0.2~0.8초 | 3 |
| 플레이어 행동 | 검 공격, 적중, 점프, 착지, 대시 | 0.1~0.25초 | 4 |
| 시간 | 시계 전진(+1시간), 재탄생 | 1.0초 / 6장 | 3 |
| UI | 카드 호버, 카드 선택 | 0.05초 / 0.3초 | 5 |

### 3-2. 동시 재생 규칙 [확정]
- 같은 효과음은 동시에 최대 2개(검 공격·적중은 3개).
- 위험 예고가 울리는 동안 우선순위 4~5는 음량을 줄인다(덕킹).
- 반복 입력음(공격·점프·착지)은 음높이를 약간씩 무작위로 바꿔 피로를 줄인다.

### 3-3. 원칙
- 실패·피격음은 짧고 둔탁하게. 플레이어를 과하게 위축시키지 않는다.
- 소리로만 전달되는 정보는 없다. 위험 예고·축적 스택 등은 화면에도 표시된다(ArtSpecification 4-1, 5-1).

## 4. 시작 능력 선택 [확정]
| 상황 | 소리 |
|---|---|
| 카드 호버 | 류트 한 음(카드마다 다른 음높이) |
| 액티브 카드 선택 | 금속성 칼 뽑는 소리 + 화음 |
| 패시브 카드 선택 | 부드러운 종 + 화음 |
| `[임시]` 카드 | 정식 능력과 같은 소리(시험용이므로 구분 불필요) |

- 액티브/패시브는 화면에서 모양으로도 구분되므로 소리는 보조 수단이다.

## 5. 시간 권능별 사운드 콘셉트

- 원칙: ArtSpecification 4장의 형태·움직임과 짝을 맞춘다. 패턴이 미결인 권능은 **콘셉트만** 정한다.

| 장 | 권능 | 사운드 콘셉트 [확정] | 범위 |
|---|---|---|---|
| 1 | 축적 | 종이 한 음씩 올라가며 쌓임 → 한 번에 터지는 저음 | **시험판** |
| 1 | 유예 | 소리가 멈췄다가 늦게 울림(지연된 메아리) | 시험판(패턴 미결) |
| 1 | 역행 | 역재생 음, 거꾸로 감기는 현 | 시험판(패턴 미결) |
| 2 | 감속 | 음높이와 속도가 함께 늘어짐 | 확장 |
| 2 | 공유 | 두 음이 같은 박으로 맥동하는 사슬 소리 | 확장 |
| 2 | 정지 | 모든 소리가 갑자기 끊기는 무음 + 유리 금 가는 소리 | 확장 |
| 3 | 침식 | 모래가 흘러내리며 음이 깎여 나감(비트크러시) | 확장 |
| 3 | 갱신 | 끊긴 음이 다시 피어나는 상승 화음 | 확장 |
| 3 | 가속 | 템포가 빨라지는 북, 짧은 쇳소리 | 확장 |
| 4 | 분기 | 같은 선율이 여러 음높이로 갈라짐 | 확장 |
| 4 | 예지 | 6-1 참고 | 확장 |
| 4 | 순서 | 6-2 참고 | 확장 |

### 5-1. 축적 보스 효과음 [확정 패턴 기준]
| 이름 | 상황 | 소리 [확정] | 길이 |
|---|---|---|---|
| `sfx_acc_stack` | 스택 +1 | 종 한 음. 스택이 오를수록 음이 높아짐(5단계) | 0.3초 |
| `sfx_acc_warning` | 방출 예고 1.0초 | 합창이 트레몰로로 커짐 | 1.0초 |
| `sfx_acc_release` | 충격파 | 큰 종 + 저음 쿵 | 0.8초 |
| `sfx_acc_exhaust` | 탈진 2.0초 | 숨을 내쉬는 듯 꺼지는 드론, 이후 정적 | 0.6초 |
| `sfx_acc_windup` | 돌진 예비 0.4초 | 짧은 북 롤 + 쇠 긁는 소리 | 0.4초 |
| `sfx_acc_charge` | 돌진 | 바람 가르는 소리 | 0.5초 |

## 6. 특수 연출 (본편)

### 6-1. 시간 예지 [확정]
- **소리가 먼저, 행동이 나중**: 보스의 예측 공격 소리가 실제 공격보다 먼저 희미한 메아리로 들린다.
- 예측이 빗나갔을 때도 정상 결과이므로 별도의 "실패" 소리는 없다(확정 규칙: 예측 실패도 정상 전투 결과).

### 6-2. 인과 역전 (최종보스) [확정]
- **결과음이 먼저, 원인음이 나중**에 들린다(예: 피격음 → 그 뒤에 칼 휘두르는 소리).
- 결과 예약형: 예약된 결과의 소리가 낮게 반복되며 원인 시점까지 남는다.
- 체력 0 이후 사망 판정 유예 동안: 심장 박동 + 늘어진 드론. 원인을 저지하면 박동이 풀리며 화음, 저지 실패 시 박동이 멈춤.

## 7. 사망 → 재탄생 [확정, 총 2.0초 = 재탄생 대기]

| 구간 | 화면(ArtSpecification 5-2) | 소리 |
|---|---|---|
| 0.0~0.4초 | 빛이 꺼지며 쓰러짐 | 짧은 낮은 현 + BGM 페이드 아웃 시작 |
| 0.4~1.0초 | 암전 | 정적(아주 작은 바람 소리) |
| 1.0~1.6초 | "N일째 18:00" | 시계 종 한 번 |
| 1.6~2.0초 | 태양이 떠오름 | 상승 화음 → `bgm_start` 시작 |

- 의도: 되감기 소리(역재생)를 쓰지 않는다. 사망은 시간 역행이 아니다(확정 규칙).

## 8. AI 생성 + 편집 기준 [확정]

### 8-1. 프롬프트 공통 틀
```
BGM: medieval {분위기}, {악기 목록}, {선법} mode, {템포} BPM, seamless loop, no vocals lyrics
SFX: {소리 설명}, medieval fantasy game sound effect, short, dry, no music
```
- 예(`bgm_boss_accumulation`): `medieval tense boss battle, layered chant choir, bells, tabor drum, hurdy-gurdy drone, phrygian mode, 120 BPM, building repetitive ostinato, seamless loop`

### 8-2. 편집 체크리스트
- 반복 곡은 이음매 없이 루프되는지 확인(시작·끝 지점 맞춤)
- 음량 정규화(BGM과 SFX 기준 레벨 통일)
- 효과음 앞 무음 제거(입력 반응 지연 방지)
- 실제로 편집을 마치지 않은 음원은 완성 자산으로 보고하지 않는다.

## 10. 전달 사항

**dev에게**
- 재생·정지 조건: 2장 전환 조건과 5-1 상황 표 기준
- 교차 페이드, 덕킹, 동시 재생 제한(3-2)
- 음량 조절 항목은 11장 수치를 Inspector에 노출

**artist에게**
- 함께 시작·끝나야 하는 지점: 방출 예고 깜빡임 ↔ `sfx_acc_warning`, 충격파 링 ↔ `sfx_acc_release`, 사망·재탄생 4구간(7장), 시계 바늘 회전 ↔ `sfx_clock_advance`
