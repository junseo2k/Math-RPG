# 사운드 사양 (Sound Specification)

> 상위 문서: `Docs/GameDesign.md`, `Docs/VerticalSliceA.md`, `Docs/CombatDecisions.md`(이하 CD), `Docs/ArtSpecification.md`
> 범위: **시험판 A** (2D 횡스크롤 실시간 액션, 플레이어 권능 역행, 검 1종, 보스 1명 4패턴). 본편 내용은 "본편 확장"으로만 표기한다.
> 표기: **[확정]** 사용자 확정 / **[제안]** 사운드 제안(승인 전 수치·음색) / **[미결]** 미정
> 이 문서는 확정된 규칙에 소리를 붙일 뿐, 새 게임 규칙이나 보스 패턴을 추가하지 않는다.

---

## 1. 전체 방향

### 1-1. 확정 [확정]
- 음악 스타일: **중세풍**. 이집트 신화는 스토리·서사에만 쓰고, 음악에는 이집트풍을 넣지 않는다.
- 제작 수단: **AI 생성 + 편집** (8장)

### 1-2. 기준 [확정]
| 항목 | 내용 |
|---|---|
| 악기 | 류트, 허디거디, 리코더·숌, 테이버(작은 북), 종, 성가풍 합창, 저음 드론 |
| 선법 | 도리안·프리지안·믹솔리디안 등 교회 선법 중심 |
| 태양신 측 | 따뜻한 현(류트)·관(리코더), 믹솔리디안처럼 밝은 선법. "흐름"은 앞으로 진행하는 리듬 |
| 달의 시종 측 | 성가풍 합창, 차가운 종, 지속되는 드론, 프리지안. "불변"은 같은 음형의 반복 |

**의도**: 흐름(태양신)과 불변(시종)의 대립을 리듬이 나아가는가, 제자리에서 반복되는가로 들려준다.

- 플레이어 역행은 태양신 측 음색을 쓴다. 리버스(역재생) 처리는 **역행 전용**이며 다른 소리에 쓰지 않는다. **[제안]**
- 시험판 A 보스는 정체가 [미결]이므로, 달의 시종 측 음색을 쓴다고 **가정**한다. **[제안]**

## 2. 음악

시험판 A 곡 목록 **[제안]** (기존 `bgm_start`/`bgm_ch1`/`bgm_boss_accumulation`을 A 흐름에 맞게 개편):

| 곡 | 장면 | 방향 | 길이 | 반복 | 우선 | 전환 조건 |
|---|---|---|---|---|---|---|
| `bgm_stage` (기존 `bgm_ch1`) | 일반 스테이지 1·2 | 테이버 리듬 + 류트, 믹솔리디안. 앞으로 나아가는 리듬. 스테이지 2에서 악기 1층 추가 | 루프 60~90초 | O | P1 | 보스 스테이지 진입 → `bgm_boss` 1.5초 교차 페이드 |
| `bgm_boss` (기존 `bgm_boss_accumulation`) | 보스 스테이지 | 달 측 음색 [제안 가정]: 합창·드론, 프리지안, 같은 음형 반복("불변"). 종은 1kHz 이하 저음역만 | 루프 60~90초 | O | P0 | 보스 처치 확정 → 0.3초 페이드 아웃 후 `sfx_boss_defeat` |
| `bgm_rest` (기존 `bgm_start`) | 상점·결과·영구 성장 화면 | 노을의 고요. 류트 아르페지오 + 드론. 상점에서는 리버브를 늘려 "멈춘 시간" 느낌 | 루프 30~60초 | O | P2 | 화면 진입 0.5초 교차 페이드 |

- 층 추가 기준은 시각이 아니라 **스테이지 순서**로 한다. A의 시간 표시가 [미결]이기 때문이다(VerticalSliceA 4장). 시각에 따른 층 추가는 본편 확장(9-2)으로 옮긴다.
- `bgm_clear`는 A에서 쓰지 않는다. 보스 처치 후 흐름은 보상 → 결과 → 성장 → 새 순환이다(CD12).
- 사망 시 BGM은 1.0초 페이드 아웃(7장), 결과·성장 화면에서 `bgm_rest`, 새 순환 시작 시 `bgm_stage`.

## 3. 효과음

### 3-1. 재생 등급 [제안]
동시에 발생하면 숫자가 작은 등급이 우선한다. 개별 효과음 목록은 3-5.

| 등급 | 분류 |
|---|---|
| 0 | 역행 (5-3) |
| 1 | 보스 예고 (5-2) |
| 2 | 플레이어 피격·사망 |
| 3 | 보스 실행·피격·처치 |
| 4 | 플레이어 행동, 일반 적 |
| 5 | UI |

- 우선순위 P0/P1/P2는 제작 순서다. P0은 핵심 검증(역행·보스 판단·기본 타격)에 꼭 필요, P1은 손맛·진행 피드백, P2는 마감 단계.

### 3-2. 동시 재생 규칙
- **[확정]** 같은 효과음은 동시에 최대 2개(검 공격·적중은 3개).
- **[확정]** 위험 예고가 울리는 동안 등급 4~5는 음량을 줄인다(덕킹).
- **[확정]** 반복 입력음(공격·점프·착지)은 음높이를 약간씩 무작위로 바꿔 피로를 줄인다. 범위 ±5% **[제안]**.
- **[제안]** 전체 효과음 동시 보이스 24. 넘치면 가장 낮은 등급의 가장 오래된 소리부터 끊는다.
- **[제안]** 역행 정지 0.3초 동안 역행 소리 외에는 아무것도 재생하지 않는다. 역행 발동 순간 재생 중인 효과음은 20ms 페이드로 끊는다(사운드는 역행으로 복원하지 않음, CD3).
- **[제안]** 끊을 때는 항상 20ms 페이드를 써서 클릭음을 막는다.

### 3-3. 원칙
- 실패·피격음은 짧고 둔탁하게. 플레이어를 과하게 위축시키지 않는다.
- 소리로만 전달되는 정보는 없다. 위험 예고 등은 화면에도 표시된다(ArtSpecification 4-1, 5-1).

### 3-4. BGM과 효과음 공존 규칙 [제안]
- 주파수: BGM의 2~5kHz를 3~4dB 줄인다(검 타격·예고 종 대역). BGM 80Hz 이하는 가볍게 해서 보스 실행·착탄의 저음을 비워 둔다.
- 독점: 리버스 처리는 역행 전용, 높고 차가운 종(2~3kHz)은 보스 예고 전용. 보스 BGM의 종은 1kHz 이하 저음역만 쓴다.
- 기준 음량: BGM 통합 약 -20 LUFS, 효과음 피크 -6dBFS, 보스 예고·역행 피크 -3dBFS.

| 덕킹 상황 | BGM | 효과음 등급 4~5 | 시작 / 복귀 |
|---|---|---|---|
| 보스 예고 중 | -4dB | -6dB | 0.05초 / 0.3초 |
| 역행 정지 중 | -8dB + LPF 800Hz | 끊음 | 즉시 / 0.2초 |
| 플레이어 피격 | -3dB | — | 즉시 / 0.3초 |
| 클리어 보상 대기 | -6dB | — | 0.1초 / 1.0초 |

## 5. 시간 권능별 사운드 콘셉트

- 원칙: ArtSpecification 4장의 형태·움직임과 짝을 맞춘다. 패턴이 미결인 권능은 **콘셉트만** 정한다.

| 장 | 권능 | 사운드 콘셉트 [확정] | 범위 |
|---|---|---|---|
| 1 | 축적 | 종이 한 음씩 올라가며 쌓임 → 한 번에 터지는 저음 | 본편 확장 (A 보스는 권능 미사용, CD7) |
| 1 | 유예 | 소리가 멈췄다가 늦게 울림(지연된 메아리) | 본편 확장 |
| 1 | 역행 (보스 권능) | 역재생 음, 거꾸로 감기는 현 | 본편 확장. 시험판 A의 역행은 **플레이어 권능**이며 5-3에서 태양신 측 음색으로 다룬다 |
| 2 | 감속 | 음높이와 속도가 함께 늘어짐 | 확장 |
| 2 | 공유 | 두 음이 같은 박으로 맥동하는 사슬 소리 | 확장 |
| 2 | 정지 | 모든 소리가 갑자기 끊기는 무음 + 유리 금 가는 소리 | 확장 |
| 3 | 침식 | 모래가 흘러내리며 음이 깎여 나감(비트크러시) | 확장 |
| 3 | 갱신 | 끊긴 음이 다시 피어나는 상승 화음 | 확장 |
| 3 | 가속 | 템포가 빨라지는 북, 짧은 쇳소리 | 확장 |
| 4 | 분기 | 같은 선율이 여러 음높이로 갈라짐 | 확장 |
| 4 | 예지 | 6-1 참고 | 확장 |

### 5-2. 시험판 A 보스 예고·실행 체계 [제안]
패턴 이름·예고 시간은 CD7 표 기준(수치 [임시]). 보스 음색은 달의 시종 측이라는 **[제안] 가정**이다(보스 정체 [미결]).

**구분 원칙**
- 2층 구조: 모든 예고는 **공통 위험 신호**(높고 차가운 종 "칭")로 시작하고, 그 위에 **패턴 고유 신호**가 이어진다.
- 예고 = 음정 있음, 상승하거나 지속, 강한 타격음 없음. 실행 = 음정 없는 잡음성 타격, 하강.
- 예고음은 예고 종료 프레임에 20ms 컷 → 실행 직전 짧은 빈틈.
- 공통 신호는 결정 프레임(= 예고 시작, CD6)에 울린다. "그 소리를 들었으면 결정 이후"를 귀로 배울 수 있다.
- 위험 범위는 화면에도 표시된다(VerticalSliceA 6장). 소리는 보조 수단이다.

| ID | 재생 조건 | 길이 | 음색·분위기 | 우선 | 반복 | 중복 처리 | 원본 |
|---|---|---|---|---|---|---|---|
| `sfx_boss_tell_common` | 결정 = 예고 시작 프레임, 4패턴 공통 | 0.25초 | 높고 차가운 종(2~3kHz) + 낮은 드론 스웰 | P0 | X | 동시 1, 등급 1. 예고 끝까지 등급 4~5 -6dB, BGM -4dB | B(고음) + Drone |
| `sfx_boss_tell_downslash` (내려베기 예고) | 예고 시작 | 0.6초 (= 예고 시간) | 칼날을 끌어올리는 쇠 긁힘이 한 번 상승 | P0 | X | 동시 1, 예고 종료 프레임 컷 | S |
| `sfx_boss_tell_dash` (돌진 예고) | 예고 시작 | 0.8초 | 빨라지는 테이버 북 롤 + 쇠 긁힘 + 발 구르기 2회 | P0 | X | 동시 1, 종료 프레임 컷 | S + 북 |
| `sfx_boss_tell_volley` (탄막 예고) | 예고 시작 | 0.6초 | 차가운 종 틱 3번(0.2초 간격, 음 상승). 탄 수 3을 소리로 전달 | P0 | X | 동시 1, 종료 프레임 컷 | B ×3 |
| `sfx_boss_tell_fall` (낙하 광역 예고) | 예고 시작 | 1.2초 | 합창 트레몰로 크레셴도 + 위에서 하강하는 휘파람 | P0 | X | 동시 1, 종료 프레임 컷 | Choir + Wind |
| `sfx_boss_exec_downslash` (내려베기 실행) | 실행 시작, 명중 프레임에 타격 피크 | 0.4초 | 무거운 휘두름 + 지면 쿵 | P0 | X | 동시 1 | W(-5반음) + D |
| `sfx_boss_exec_dash` (돌진 실행) | 실행 시작~돌진 끝 | 0.5초 | 바람을 가르는 굉음 + 발 구름 | P0 | X | 동시 1, 보스가 멈추면 끊음 | Wind |
| `sfx_boss_exec_volley` (탄막 실행) | 탄 1발 발사마다 (×3) | 0.2초 | 짧은 발사음 "퓩". 발마다 음정 한 단계 하강 | P0 | X | 동시 3 | W (짧게) |
| `sfx_boss_exec_fall` (낙하 광역 실행) | 각 지점 착탄 프레임 | 0.6초 | 큰 종 + 저음 쿵 | P0 | X | 동시 3, 지점별 ±3%. 같은 프레임 2개 이상이면 1개만 +3dB | B(저음) + D |
| `sfx_boss_hurt` | 보스 피해 적용 | 0.15초 | 무겁고 낮은 갑옷 울림 | P1 | X | 동시 1, 0.08초 재발동 제한. sword_hit 위에 겹침 | T(-4반음) + B 저음 |

- 예고 시간을 Inspector에서 바꾸면 예고음은 종료 프레임에서 잘린다. 늘리면 마지막 지속음을 늘인 버전이 필요하다.

**역행 후 재개 규칙** (사운드는 복원하지 않으므로, CD3)
- 결정 이후로 복원(보스가 예고 중): 공통 신호를 -3dB로 다시 재생하고, 패턴 예고음은 복원된 예고 진행도 위치부터 재생한다.
- 결정 이전으로 복원: 예고음 없음. 다음 결정 때 정상 재생한다.
- 따라서 소리만으로 "같은 공격이 이어진다"와 "다시 선택된다"를 구분할 수 있다.
- 실행 중으로 복원: 이미 지나간 발사·착탄은 재생하지 않고, 다음 이벤트부터 정상 재생한다.

### 5-3. 플레이어 역행 사운드 [제안]
역행 수치(역행 거리 2초, 정지 연출 0.3초, 직후 무적 0.2초, 쿨타임 20초)는 VerticalSliceA 7-4 기준 [임시].

```
t=0.00  입력 = 복원      cast(틱) + flow 시작. 다른 효과음 20ms 컷, BGM -8dB·LPF 800Hz
t=0.00~0.30 정지 연출    flow: 태양 모티프 역재생 + 리버스 종 스웰 (점점 커짐)
t=0.30  재개             flow 절단 → restore 종 정방향 한 음
t=0.30~0.50 무적 0.2초   restore 반짝임 유지 → 0.50에 급감(= 무적 종료). BGM 0.2초에 걸쳐 복귀
```

| ID | 재생 조건 | 길이 | 음색·분위기 | 우선 | 반복 | 중복 처리 | 원본 |
|---|---|---|---|---|---|---|---|
| `sfx_rewind_cast` (역행 발동) | 역행 입력 수락 프레임 = 복원 순간 | 0.06초 | 시계 톱니 "틱" + 류트 현 튕김. 즉시 반응 확인 | P0 | X | 동시 1, 등급 0. 다른 효과음 전부 20ms 컷 | Tick + M |
| `sfx_rewind_flow` (시간 역류) | 정지 연출 전체 | 정확히 0.30초 | 태양 모티프(류트 3음 상행) 역재생 + 리버스 종 스웰. 0.3초에 끊김 | P0 | X | 동시 1. 끝 지점을 재개 프레임에 맞춘다(연출 시간이 바뀌면 시작 위치를 옮김) | M + B 역재생 (스테레오) |
| `sfx_rewind_restore` (시간 복원 완료) | 정지 연출 끝 = 재개 프레임 | 0.5초 (핵심 0.2초 = 무적, 잔향 0.3초) | 따뜻한 종 정방향 한 음(모티프 첫 음) + 밝은 반짝임, 0.2초 뒤 급감 | P0 | X | 동시 1 | B + M |
| `sfx_rewind_ready` (쿨타임 완료) | 역행 쿨타임 0 도달 프레임 | 0.4초 | 태양 모티프 3음 정방향(류트 + 작은 종), 작고 밝게 | P1 | X | 동시 1. 보스 예고 중이면 -6dB로 재생(지연 없음) | M |
| `sfx_rewind_denied` (사용 불가) | 쿨타임 중 역행 입력 (CD4 "사용 불가 피드백") | 0.1초 | 막힌 톱니의 둔탁한 "딸깍" 2번, 음정 없음 | P0 | X | 동시 1, 0.25초 내 재입력 무시 | Tick (LPF) |

**일반 마법과 구분되는 근거**
1. 엔벨로프 반전: 일반 마법은 "공격음 → 감쇠", 역행은 "스웰 → 절단". 리버스 처리는 역행만 쓴다(7장 사망 역재생 금지와 같은 방향).
2. 태양신 모티프: 반짝임 대신 주인공의 태양 모티프(류트, 믹솔리디안)를 거꾸로 돌린다. 1-2의 "흐름 = 앞으로 진행하는 리듬"을 뒤집어 "자기 시간을 되감는다"를 들려준다. 쿨타임 완료음은 같은 모티프를 정방향으로 연주해 짝을 맞춘다.
3. 세계의 소리를 멈추는 것은 역행뿐: 효과음 컷 + BGM 필터. 정지 중 입력 무시(CD4)를 소리로도 전달한다.
4. 판정 경계와 일치: 역류음이 끊기는 순간 = 재개, 반짝임이 꺼지는 순간 = 무적 종료. 소리만으로 "이제 움직일 수 있다", "이제 맞는다"를 알 수 있다.

## 6. 특수 연출 (본편)

### 6-1. 시간 예지 [확정]
- **소리가 먼저, 행동이 나중**: 보스의 예측 공격 소리가 실제 공격보다 먼저 희미한 메아리로 들린다.
- 예측이 빗나갔을 때도 정상 결과이므로 별도의 "실패" 소리는 없다(확정 규칙: 예측 실패도 정상 전투 결과).

### 6-2. 인과 역전 (최종보스) [확정]
- **결과음이 먼저, 원인음이 나중**에 들린다(예: 피격음 → 그 뒤에 칼 휘두르는 소리).
- 결과 예약형: 예약된 결과의 소리가 낮게 반복되며 원인 시점까지 남는다.
- 체력 0 이후 사망 판정 유예 동안: 심장 박동 + 늘어진 드론. 원인을 저지하면 박동이 풀리며 화음, 저지 실패 시 박동이 멈춤.

- 역행: 발동 프레임에 진행 중인 효과음 20ms 컷, 정지 중 역행 소리만 재생, 재개 후 0.2초에 걸쳐 BGM 복귀(5-3)
- 역행 후 보스 예고음: 복원된 예고 진행도 위치부터 재생, 결정 이전 복원이면 재생 안 함(5-2 재개 규칙)
- 음량 조절 항목은 11장 수치를 Inspector에 노출

**artist에게** — 함께 시작·끝나야 하는 지점 [제안]
- 보스 예고 시작(위험 범위 표시 시작) ↔ `sfx_boss_tell_common` + 패턴 예고음, 예고 종료 ↔ 예고음 컷
- 낙하 광역 착탄 ↔ `sfx_boss_exec_fall`
- 역행 정지 연출 0.3초 ↔ `sfx_rewind_flow`, 재개 순간 ↔ `sfx_rewind_restore` 시작
- 역행 직후 무적 0.2초 시각 효과 ↔ `sfx_rewind_restore` 반짝임 구간
- 역행 쿨타임 아이콘이 다 찬 순간 ↔ `sfx_rewind_ready`
- 상점 통로 시각 단서 ↔ `sfx_shop_portal_hint`
- 사망 연출(7장) ↔ `sfx_player_death`, BGM 페이드 아웃

## 11. 조절 수치 [제안 기본값]

기존 문서에는 항목만 있고 값은 정해지지 않았다. 아래 값은 모두 **[제안]**이며 Inspector 초기값으로만 쓴다.

| 분류 | 항목 | 제안 기본값 |
|---|---|---|
| 음량 (슬라이더 0~1) | 마스터 | 1.0 (0dB) |
| 음량 | BGM | 0.6 (약 -4.4dB) |
| 음량 | 효과음 | 0.85 (약 -1.4dB) |
| 음량 | UI | 0.7 (약 -3.1dB) |

| 음량 | 역행 효과음 (신설, 별도 그룹, 덕킹을 받지 않음) | 0.9 |
| 전환 | BGM 교차 페이드: 스테이지→보스 / 화면 전환 | 1.5초 / 0.5초 |
