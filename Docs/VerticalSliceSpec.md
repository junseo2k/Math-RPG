# 시험판 명세 (Vertical Slice Spec)

> 상위 문서: `Docs/GameDesignOverview.md`
> 표기: **[확정]** 사용자 확정 / **[제안]** 승인 전 제안 / **[미결]** 미정

---

## 1. 시험판 목표

첫 번째 플레이 가능한 빌드로 다음을 확인한다.

- 2D 횡스크롤 검 전투가 조작하기 쉽고 손맛이 있는가
- 스테이지 진행에 따라 시간이 흐른다는 것을 체감하는가
- 시종 보스 3명의 권능 패턴이 서로 구분되는가
- 시작 능력 선택이 플레이에 차이를 만드는가
- 사망 → 다음 날 18:00 재탄생 순환이 자연스러운가

---

## 2. 한 판 흐름 [확정]

```
게임 진입 → 시작 지점: 시작 능력 선택
  → 일반 → 일반 → 보스1(축적)
  → 일반 → 일반 → 보스2(유예)
  → 일반 → 일반 → 보스3(역행)
  → 시험판 클리어

어느 지점에서든 사망 → 다음 날 18:00 재탄생 → 시작 지점(전부 초기화)
```

- 1장(탄생) 18:00~21:00, 스테이지 9개.
- 보스 배치 순서(축적→유예→역행)는 GameDesignOverview 5-1의 나열 순서를 따른다.

## 3. 기능 명세

### F1. 플레이어 이동·전투 [확정]

| 항목 | 내용 |
|---|---|
| 플레이어 행동 | 좌우 이동, 점프, 검 공격, 대시 |
| 발동 조건 | 입력 시. 대시는 재사용 대기시간 동안 사용 불가 |
| 결과 | 검 공격 범위 안의 적에게 피해. 대시는 짧은 거리 빠르게 이동 |
| 실패 처리 | 체력 0 → F6 사망 |
| 조절 수치 | 체력, 공격 피해, 공격 간격, 이동 속도, 점프 높이, 대시 거리·대기시간 |

- **[확정]** 입력 키: 이동 ←/→, 점프 Space, 공격 A, 대시 Shift
- **[확정]** 대시 중 무적
- **[확정]** 공중 공격 허용, 공중 대시 불가(지상에서만)
- **[확정·임시 기본값]** 체력 5, 공격 피해 1, 공격 간격 0.35초, 공격 범위 앞 1.2×1, 이동 속도 6, 점프 약 3칸, 대시 약 3칸·무적 0.15초·대기 0.6초, 피격 후 무적 0.5초. 플레이테스트 후 조정

### F2. 시작 능력 선택 [확정]

| 항목 | 내용 |
|---|---|
| 플레이어 행동 | 시작 지점에서 제시된 능력 중 1개 선택 |
| 발동 조건 | 게임 진입 직후, 재탄생 직후 |
| 결과 | 선택한 능력이 이번 판 동안 적용됨 |
| 실패 처리 | 선택 전에는 첫 스테이지로 진행 불가 |
| 조절 수치 | 후보 수(시험판 3), 표시 수(3) |

- 시험판은 시험용 **임시 능력 3개**만 사용하며, 3개 모두 제시된다. 정식 후보 10개 / 표시 3개 무작위는 본편에서 적용.
- **[확정]** 임시 능력 3개: 순간 정지장(액티브), 잔광(패시브), 가벼운 발걸음(패시브). 상세: `Docs/StartAbilities_Slice.md`

### F3. 스테이지 진행과 시간 전진 [확정]

| 항목 | 내용 |
|---|---|
| 플레이어 행동 | 방을 클리어하고 출구로 이동 |
| 발동 조건 | 방 클리어 후 출구 진입 |
| 결과 | 다음 방으로 이동. 보스 처치 시 게임 내 시각 전진 |
| 실패 처리 | 해당 없음 |
| 조절 수치 | 보스당 시간 전진량(기본 1시간) |

- **[확정]** 시간은 **보스를 쓰러뜨릴 때마다 1시간** 전진한다. 일반 방 클리어로는 전진하지 않는다(18:00 → 보스3 처치 시 21:00).
- **[미결]** 현재 시각을 화면에 표시하는 방식

### F4. 일반 방 [확정]

| 항목 | 내용 |
|---|---|
| 플레이어 행동 | 방 안의 적을 처치 |
| 발동 조건 | 방 진입 시 출구 잠김 |
| 결과 | 적 전멸 시 출구 개방 |
| 실패 처리 | 체력 0 → F6 사망 |
| 조절 수치 | 적 수, 적 체력·공격력·이동 속도 |

- **[확정]** 가로로 긴 방(카메라 스크롤), 근접 순찰형 적 1종, 뒤쪽 방일수록 적 증가, 여러 방 형태 중 매 판 무작위. 상세: `Docs/NormalRoom.md`
- **[미결]** 방 클리어 보상 유무

### F5. 시종 보스 3명 [확정]

| 항목 | 내용 |
|---|---|
| 플레이어 행동 | 보스 패턴을 피하며 공격 |
| 발동 조건 | 보스 방 진입 |
| 결과 | 보스 체력 0 → 출구 개방. 보스3 처치 시 시험판 클리어(F7) |
| 실패 처리 | 체력 0 → F6 사망 |
| 조절 수치 | 보스 체력, 공격력, 능력 발동 간격 |

- 각 보스는 자신의 고유 권능(축적·유예·역행)을 그대로 쓰는 패턴으로 구현한다.
- 보스 처치 시 권능을 임시 권능으로 얻는 규칙은 **본편으로 미룬다**.
- 보스별 상세: `Docs/Bosses/01_Accumulation.md`(축적), `Docs/Bosses/02_Deferral.md`(유예), `Docs/Bosses/03_Reversal.md`(역행)

### F6. 사망과 재탄생 [확정]

| 항목 | 내용 |
|---|---|
| 플레이어 행동 | 없음(자동) |
| 발동 조건 | 플레이어 체력 0 |
| 결과 | 다음 날 18:00에 시작 지점에서 재탄생 → F2 시작 능력 다시 선택 |
| 실패 처리 | 해당 없음 |
| 조절 수치 | 사망 연출 길이, 재탄생까지의 대기 시간(기본 2초) |

- 초기화: 스테이지 진행, 시작 능력, 전투 능력치.
- 시험판에는 영구 성장이 없으므로 유지되는 플레이 요소는 없다.
- **[제안]** 재탄생할 때 "N일째"를 표시해 '다음 날'임을 보여준다.

### F7. 결과 화면 [확정]

| 항목 | 내용 |
|---|---|
| 발동 조건 | 보스3 처치(클리어) / 사망 |
| 결과 | 클리어: 시험판 종료 화면. 사망: 재탄생으로 연결 |

- **[확정]** 클리어 화면: 도달 시각("21:00 도달"), 며칠째, 플레이 시간(능력 선택 ~ 클리어).
- **[확정]** 버튼: **처음부터 다시**(유지 상태까지 초기화, 1일째부터) / **종료**.

## 4. 시험판 포함 / 본편 확장

| 시험판 포함 [확정] | 본편 확장 |
|---|---|
| 2D 횡스크롤 이동·점프·검 공격·대시 | 2~4장 |
| 시작 능력 선택(임시 3개) | 정식 시작 능력 10개, 무작위 3개 제시 |
| 1장 9스테이지, 18:00~21:00 시간 전진 | 나머지 시종 9명 |
| 일반 방(적 전멸 → 출구 개방) | 특수 보스(분기·예지·최종) |
| 시종 보스 3명(축적·유예·역행) | 예지 보스 GRU AI |
| 사망 → 다음 날 18:00 재탄생(전부 초기화) | 보스 처치 시 임시 권능 획득 |
| 클리어·사망 결과 화면 | 챕터 종료 특수 시간 능력 |
| | 영구 성장, 저장 기능 |
| | 희귀 무기, 챕터 보상 |
| | 시종의 재회 반응(기억 연출) |

## 6. 조절 수치 (값 미정)

| 분류 | 항목 |
|---|---|
| 플레이어 | 체력, 공격 피해, 공격 간격, 이동 속도, 점프 높이, 대시 거리, 대시 대기시간 |
| 시작 능력 | 후보 수(정식 10 / 시험판 3), 표시 수(3) |
| 일반 방 | 적 수, 적 체력·공격력·이동 속도 |
| 보스 | 체력, 공격력, 능력 발동 간격 |
| 시간 | 보스당 시간 전진량(1시간) |
| 재탄생 | 사망 연출 길이, 재탄생 대기 시간(2초) |

- 모든 값은 Inspector에서 조절 가능하게 하며, 기본값은 사용자 승인 전까지 정하지 않는다.
