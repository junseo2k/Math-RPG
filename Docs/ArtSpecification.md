# 아트 사양 (Art Specification)

> 상위 문서: `Docs/GameDesignOverview.md`, `Docs/VerticalSliceSpec.md`, `Docs/Bosses/01_Accumulation.md`
> 표기: **[확정]** 사용자 확정 / **[제안]** 승인 전 제안 / **[미결]** 미정
> 이 문서는 확정된 게임 규칙을 시각화할 뿐, 새 규칙을 추가하지 않는다.

---

## 1. 시각 방향

### 1-1. 확정 [확정]
- 그림체: **픽셀아트**
- 제작 수단: **AI 생성 + 보정** (7장 프롬프트·보정 기준 참고)
- 2D 횡스크롤, 시간 테마. 시각 스타일은 **중세풍**
- 이집트 신화는 **스토리·서사에만** 쓰고, 시각 요소(배경·UI·캐릭터·이펙트)에는 이집트풍을 넣지 않는다

### 1-2. 제안 [제안]
| 항목 | 제안값 | 이유 |
|---|---|---|
| 기준 해상도 | 640×360 → 1920×1080(3배) | 정수 배율로 픽셀이 깨지지 않음 |
| PPU(Pixels Per Unit) | 32 | 현재 플레이어 충돌체 1×1 유닛 = 32×32px |
| 주인공 프레임 | 48×48px (몸통 약 32×32) | 검 휘두름·대시 잔상 여유 |
| 시종 보스 프레임 | 96×96px (몸통 약 64×64) | 현재 보스 충돌체 2×2 유닛 |
| 팔레트 | 32색 이내 공용 팔레트 | AI 생성물 색 통일 |

- dev 전달: Pixel Perfect Camera 사용 시 카메라 크기는 기준 해상도에 맞춰 조정 필요(현재 TestArena 카메라 크기 6은 임시).

### 1-3. 색 체계 [제안]
| 대상 | 색 | 의미 |
|---|---|---|
| 태양신(주인공) | 금색·백열 | 흐름, 생명 |
| 달의 시종 | 은색·차가운 청색 | 불변, 영원한 밤 |
| 밤하늘 | 시간대별로 변화(3장) | 시간 진행 |
| 위험 예고 | 흰색 깜빡임 + 형태 표시 | 색만으로 구분하지 않음 |

- **[제안]** 중세 모티브(채식 필사본 테두리, 스테인드글라스, 고딕 아치, 천문 시계, 모래시계, 태양 문장)는 **배경과 UI 장식**에 쓰고, 전투 정보 판독을 방해하지 않게 한다.

## 2. 화면 구성

### 2-1. 시작 지점 · 능력 선택 [확정 규칙 기반]
- 규칙: 게임 진입 후 시작 지점에서 제시된 능력 중 1개 선택(시험판은 임시 3개 모두 제시).

| 요소 | 내용 |
|---|---|
| 카드 3장 | 가로 배치. 이름, 종류(액티브/패시브), 설명 |
| 종류 구분 | **아이콘 모양 + 글자**: 액티브 = 검 모양 테두리, 패시브 = 원형 테두리 |
| 임시 표시 | 시험판 임시 능력에는 `[임시]` 배지. 실제 능력으로 오인되지 않게 |
| 선택 피드백 | 커서/호버 시 카드 확대 + 테두리 금색, 선택 시 카드가 빛나며 다른 카드 어두워짐 |
| 배경 | 시작 지점(18:00 노을), 태양 문장 스테인드글라스 |

- **[확정]** 카드 크기 기준 해상도 140×200px, 카드 간격 24px, 선택 연출 0.3초.

### 2-2. 전투 HUD
| 위치 [확정] | 요소 | 표시 방식 |
|---|---|---|
| 좌상단 | 플레이어 HP | 태양 문장 아이콘 5개(칸). 피격 시 칸이 깨지며 흔들림 |
| 좌상단 아래 | 선택한 시작 능력 | 아이콘 + 이름 |
| 좌상단 아래 | 대시 재사용 | 아이콘이 차오름. 사용 가능 시 반짝임 |
| 상단 중앙 | 현재 시각 · 며칠째 | 시계(3장) + "N일째" |
| 상단 중앙 아래 | 스테이지 진행 | 9칸 막대. 일반 방 = 작은 사각, 보스 방 = 큰 마름모(**모양으로 구분**) |
| 하단 중앙 | 보스 HP · 이름 | 보스 방에서만 표시 |
| 보스 머리 위 | 권능 게이지 | 축적 스택 등(4장) |

- HUD는 화면 가장자리에만 두어 전투 영역을 가리지 않는다.

### 2-3. 결과 화면
| 화면 | 내용 |
|---|---|
| 시험판 클리어 | "21:00 도달", 며칠째, 사망 횟수 |
| 사망 | 5장 사망·재탄생 연출로 연결(별도 화면 없음) |

- **[확정]** 클리어 화면: 도달 시각, 며칠째, 플레이 시간 + **처음부터 다시** / **종료** 버튼(VerticalSliceSpec F7)

## 3. 시간 진행 시각화

| 요소 | 내용 |
|---|---|
| 하늘 그라데이션 [확정] | 18:00 노을(주황·보라) → 19:00 → 20:00 → 21:00 남색. 1장은 4단계 |
| 시계 UI [확정] | 중세 천문 시계 모양, 태양 바늘. 1시간 = 바늘 한 칸 |
| 시각 전진 연출 [확정] | 보스 처치 시 시계 바늘이 돌고 "+1시간", 하늘색 전환 1.0초 |
| 06:00 연결 [제안] | 바늘이 06:00을 지나며 18:00으로 이어지는 고리 연출(본편, 시험판 미도달) |

- 규칙: 시간은 보스 처치마다 1시간 전진(확정). 일반 방 클리어로는 시각 변화 없음.

## 4. 시간 권능 시각 구분

- 원칙: 권능마다 **형태 · 움직임 · 색** 세 가지를 함께 정한다. 색만으로 구분하지 않는다.
- 아래는 **모티브 언어**이며, 패턴이 미결인 권능의 구체 이펙트는 정하지 않는다.

| 장 | 권능 | 형태 [제안] | 움직임 [제안] | 색 [제안] | 범위 |
|---|---|---|---|---|---|
| 1 | 축적 | 차오르는 동심원 고리 | 단계적으로 겹쳐 커짐 → 한 번에 터짐 | 금색 → 백열 | **시험판** |
| 1 | 유예 | 공중에 멈춘 모래알, 점선 윤곽 | 멈춤 → 늦게 발동 | 호박색 | 시험판(패턴 미결) |
| 1 | 역행 | 반시계 나선, 거꾸로 흐르는 잔상 | 잔상이 역재생 | 청록 | 시험판(패턴 미결) |
| 2 | 감속 | 늘어지는 잔상 | 느린 파동 | 남색 | 확장 |
| 2 | 공유 | 두 대상을 잇는 사슬 | 연결선 맥동 | 보라 | 확장 |
| 2 | 정지 | 금 간 유리 프레임 | 완전 정지, 채도 제거 | 흰색·회색 | 확장 |
| 3 | 침식 | 부서져 흩어지는 모래 | 가장자리부터 갉아먹음 | 황토 | 확장 |
| 3 | 갱신 | 돋아나는 싹, 원형 재생 | 되살아나는 빛 | 녹색 | 확장 |
| 3 | 가속 | 날카로운 속도선 | 빠른 점멸 | 주황·적색 | 확장 |
| 4 | 분기 | 갈라지는 반투명 분신 | 여러 경로로 퍼짐 | 은색 | 확장 |
| 4 | 예지 | 먼저 그려지는 유령 윤곽 | 실루엣이 앞서 이동 | 시안 | 확장 |
| 4 | 순서 | 뒤바뀐 원인·결과 표식(채식 문자 번호) | 결과가 먼저 나타나고 원인이 뒤따름 | 흑색·금색 | 확장 |

### 4-1. 축적 보스 이펙트 [확정, 현재 구현 기준]
| 상황 | 표현 |
|---|---|
| 축적 스택 | 머리 위 게이지 (임시: `축적 [##---]` 글자) → 최종: 고리 5개가 차오름 |
| 방출 예고 1.0초 | 보스 흰색 깜빡임 → 최종: 고리가 백열하며 진동 |
| 충격파 | 반경 3.5 원 표시 0.2초 → 최종: 금빛 링이 퍼지는 4~6프레임 |
| 탈진 2.0초 | 보스 어두워짐 → 최종: 웅크린 자세 + 모래가 흘러내림 |
| 돌진 예비 0.4초 | 주황색 → 최종: 몸을 낮추는 자세 + 발밑 먼지 |

## 5. 공통 피드백 · 사망과 재탄생

### 5-1. 공통 피드백 [제안]
| 상황 | 표현 | 길이 |
|---|---|---|
| 검 공격 | 금색 호 궤적 3프레임 | 0.1초 |
| 적 피격 | 흰색 번쩍 + 작은 경직 | 0.08초 |
| 플레이어 피격 | 빨간 번쩍 + 화면 흔들림 약 + 무적 동안 반투명 깜빡임 | 무적 0.5초(확정값) 동안 |
| 대시 무적 | 금색 잔상 2~3개 | 0.15초(확정값) |
| 위험 예고 | 흰색 깜빡임 + 범위 윤곽선 | 패턴별 예고 시간 |

### 5-2. 사망 → 재탄생 [확정, 총 2.0초 = 재탄생 대기]
| 구간 | 연출 |
|---|---|
| 0.0~0.4초 | 주인공의 빛이 꺼지며 쓰러짐 |
| 0.4~1.0초 | 화면 암전 |
| 1.0~1.6초 | 검은 화면에 "N일째 18:00" |
| 1.6~2.0초 | 지평선에서 태양이 떠오르며 시작 지점으로 → 능력 선택 |

- 의도: 되감기가 아니라 "다음 날"임을 보여준다(사망 ≠ 시간 역행, 확정 규칙).

### 6-2. 본편 확장
- 유예·역행 보스 및 이펙트(패턴 확정 후 시험판으로 이동 가능)
- 2~4장 시종 9명, 특수 보스(분기·예지·최종) 이펙트
- 2~4장 배경, 06:00 연결 연출
- 정식 시작 능력 10개 아이콘, 권능 획득 연출
- 희귀 무기: 이집트 신성 도구의 **의미만** 가져오고 **외형은 중세풍 무기·성물**로 해석한다 [확정]. 목록·효과는 기획 미결

## 7. AI 생성 + 보정 기준

### 7-1. 프롬프트 공통 틀 [제안]
```
pixel art, {크기}px sprite sheet, side view 2D platformer,
medieval dark fantasy, {대상 설명}, {상태 목록},
limited palette, transparent background, no anti-aliasing, crisp pixels
```
- 예(주인공): `fallen sun deity in worn knightly garb, longsword, golden sun emblem, faint halo` + `idle, run, jump, attack, dash, hurt, death`

### 7-2. 보정 체크리스트
- 크기를 정확한 픽셀 격자로 다시 맞춤(흐린 픽셀·안티앨리어싱 제거)
- 공용 팔레트로 색 감소
- 프레임 간 위치·크기 정렬(피벗 일치)
- 배경 완전 투명 확인
- 실제로 보정을 마치지 않은 이미지는 완성 자산으로 보고하지 않는다.

- **[미결]** 사용할 AI 생성 도구와 상업적 이용 조건(확인 전 단정하지 않음)

## 8. 전달 사항

**dev에게**
- 자산 이름 규칙 [제안]: `chr_player_{상태}`, `boss_accumulation_{상태}`, `fx_{이름}`, `ui_{이름}`
- 스프라이트 Import: Point 필터, 압축 없음, PPU 32
- 축적 보스 게이지·예고·충격파는 현재 임시 표현(4-1) → 자산 준비 후 교체
- HUD는 2-2 배치 기준, 화면 크기 변화 시 가장자리 고정

**planner에게**
- 일반 적 설계(F4)가 정해져야 적 자산 제작 가능
- 유예·역행 패턴 확정 시 4장 모티브를 이펙트로 구체화
