## 생성 조건 (PixelLab MCP)

- 타일: `create_topdown_tileset`, mode `pro`, view `low top-down`, tile 32, roundness 0, shading `medium`, detail `low`
  - 물: transition 0.25 / 마른 v4: transition 0.25, upper_base_tile_id = 물 세트 바닥 / 벽: transition 1.0, lower_base_tile_id = 같은 바닥
  - 마른 v4 lower 설명: `plain flat dried grey-brown mud, almost featureless, only very soft subtle tonal mottling, no lines, no cracks…`
- 장식물: `create_image_pro`, 투명 배경. 참조 이미지 2장(배치 시안 일부 128×128 = 재질·시점, 주인공 1프레임 = 픽셀 밀도·외곽선). 균열 데칼은 배치 시안 일부만 참조
- 균열을 타일에서 데칼로 뺀 이유: Wang 세트는 지형 하나를 채우는 타일이 1장뿐이라, 큰 균열을 타일에 그리면 32px마다 똑같이 반복된다
- 사용량: 타일 6세트 × 15 + 장식물·데칼 4회 × 10 = 130 generations
- 확인한 PixelLab 기능: Wang 타일셋(2지형, base tile ID로 연결), 벽 높이 transition, 참조 이미지(create_image_pro, 최대 4장), 투명 출력. 타일셋 생성에는 스타일 참조 이미지가 없다. 한 타일셋은 지형 2개만 담는다.

## 검수

| 질문 | 결과 |
|---|---|
| 신성한 지하수로로 읽히는가 | △ 정돈된 석조와 남청색 초승달 깃발·제단으로 종교 시설인 것은 읽힌다. 장식이 작아 "달 신앙"은 가까이 봐야 보이고, 전체로는 일반 석조 던전에 가깝다 |
| 바닥·경계 구분 | ○ 물(어두운 청록·물결), 바닥(회청 석판), 마른 바닥(회갈 판 균열)이 색과 무늬 모두 다르다. 수로 둑과 벽 앞면이 경계를 선으로 끊어 준다 |
| 같은 장소의 두 현실로 보이는가 | ○ (v4 이후) 둑 모양과 위치가 같고, 마른 쪽은 평평한 진흙 + 둑 아래 물 자국 띠 + 큰 균열 두 군데라 "물이 빠진 같은 수로"로 읽힌다. 균열 데칼 선이 주인공 외곽선만큼 어두워 조금 튄다 |
| 타일 연결·시점 | ○ 이음새 없이 연결된다. 바닥은 32px마다 석판 줄눈이 반복되어 격자가 촘촘하게 보인다. 벽 윗면은 무늬 없는 평면이라 넓게 쓰면 비어 보인다 |
| 캐릭터·전투 효과 여유 | ○ 주인공 검은 외곽선과 금색이 세 지형 모두에서 먼저 읽힌다. 빨강 예고 원(임시 도형)도 보인다. 원본은 바닥이 밝아 1-3의 "배경은 한 단계 어둡게"를 아직 지키지 못한다. 어둡게 한 아래 시안이 더 잘 읽힌다 |
| Aseprite 수정 가능성 | ○ 타일이 무늬 단순·저디테일이라 손보기 쉽다. 다만 물 타일 193색, 마른 v4 72색, 벽 71색으로 32색 공용 팔레트를 넘는다 → 색 줄이기 필요 |

전투 효과 그림은 아직 없어 빨간 원은 코드 없이 그린 자리표시다. 걷기·공격 프레임과 실제 2D 조명을 켠 상태는 확인하지 않았다.

## 수정 우선순위

1. ~~마른 수로 바닥 재생성~~ → 완료 (v4 + 균열 데칼). 남은 Aseprite 항목: 균열 데칼 선 색을 진흙보다 한두 단계만 어둡게 낮추기
2. **배경 명도·팔레트**: 바닥·벽 명도 약 -20%, 채도 -15%, 32색 이하로 감소. 바닥 줄눈 대비를 낮춰 격자 반복을 줄인다 (Aseprite 또는 palette 지정 재생성)
3. **달 신앙 표현 강화**: 깃발을 32×64(천 길이 2배)로, 벽면 초승달 부조 1종 추가 검토. 제단은 현재 크기 유지
