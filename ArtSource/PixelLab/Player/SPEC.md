## 색·선
- 공통 팔레트 **16색**(검정 외곽선 포함), 모든 프레임이 같은 `palette.hex` — 2026-10-27 사용자 결정으로 24색에서 변경(도트 기준 통일)
- 검정 1px 외곽선, 4방향만(몸에 대각선으로만 닿는 모서리 픽셀은 비움) — 같은 날 추가
- 알파는 0 또는 255만. 디더링 없음
- 위험 빨강·백열(ArtSpecification 1-3 전용색)은 쓰지 않음

## 디자인 고정
- 헝클어진 밝은 금발(아호게 없음), 찢어지지 않은 짙은 붉은 망토(이동·회피 때 뒤로 펄럭임), 태양 장식(금색 원 + 금빛 광선) — 2026-10-28 사용자 결정으로 변경, 해진 아이보리 의복, 검은 내의·장갑, 빛바랜 금색 보호구·부츠, 검(모든 방향 무채색 회색 강철 — 2026-10-27 결정, 파란 기 제거)
- 태양 장식 = **캐릭터 자신의 오른쪽 어깨**(남향에서 화면 왼쪽). 좌우 반전만으로 방향을 만들지 않는다
- 방향·동작이 바뀌어도 머리 크기·비율·장식 위치·망토 길이·기준점 유지
- 망토는 발 위치·공격 방향을 가리지 않는다
- 프레임별 자동 잘라내기·크기 맞춤·전체 확대축소 금지. 클립 단위 고정 오프셋만 허용

### 기준 자산

### 애니메이션 방식 (검증 결과)
- 아래쪽 이동으로 비교: 템플릿(`running-8-frames`) → 검·태양 장식 소실, 마지막 프레임 튐. skeleton-v3 → 키 46→41px로 줄고 검 소실. **v3 커스텀 → 키·검·장식 유지** → 4동작 모두 v3로 통일
- v3는 기준 회전 이미지를 0번 프레임으로 넣고(`keep_first_frame`) 그 프레임으로 클립 오프셋을 구한 뒤 0번은 버림(첫 프레임 중복 없음). 클립당 오프셋 1개, 프레임별 보정 없음
