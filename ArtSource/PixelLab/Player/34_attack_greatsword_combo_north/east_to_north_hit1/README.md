# 1타: East 확정 동작을 북쪽(뒤)에서 본 자세 (2026-11-08, 비교 시안 3장)

사용자: 새 북쪽 공격을 설계하지 말고 East 3연격 동작·느낌을 뒤에서 본 자세로 옮김. 승인 전 중간 프레임·다른 타 금지.

| 순간 | East | 북쪽으로 옮긴 몸 동작 |
|---|---|---|
| 준비 | f3 | 칼을 몸 오른쪽에 세워 듦(손 = 오른 어깨 바깥 가슴 높이), 몸통 오른쪽으로 틂, 무게 뒤, 발 모음, 망토는 틀어진 반대(왼쪽 뒤)로 쏠림 |
| 베기 중간 | f4 | 깊게 앉음(무릎 바깥, 발 넓게), 상체 앞으로 숙여 짧아지고 머리 낮아짐, 칼은 무릎 높이로 몸 앞을 가로질러 왼쪽으로(몸에 가려지고 왼쪽 끝만 보임), 망토는 뒤처진 왼어깨 위로 뭉쳐 들림(오른어깨·등·허리 드러남) |
| 제동 | f7 | 왼발 앞(화면 위)·오른다리 뒤로 뻗음, 몸통 왼쪽으로 돎, 팔은 몸 왼쪽으로 뻗음, 칼은 뒤-위(뒤에서 보면 거의 수평 왼쪽), 망토는 앞-오른쪽으로 휘날림(몸 왼쪽 드러남) |

- 화면 칼 각도를 베끼지 않고 같은 신체 동작으로 옮김: East 앞(+x) → 화면 위, East 뒤 → 화면 아래(카메라 쪽, 짧아짐), 캐릭터 오른쪽 → 화면 오른쪽
- 외형: north idle 머리·등판 무늬(`../body_under_cape/`)·팔레트. 팔다리·망토·칼은 새로 그림. 생성 호출 없음. 14~15색, 알파 0/255, 바닥 y94
