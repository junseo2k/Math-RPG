# 북쪽 3연격 밑그림 v3 — 망토 분리 (2026-11-08, 후보)

사용자: v2는 "너무 다같이 움직임, 망토 모양 고정 문제" → 망토를 몸과 따로, 안의 몸은 드러냄(`../body_under_cape/`).

- 만들기: `cd ArtSource/PixelLab/Player/tools && python attack_north_combo_cape_stick.py` (종료 코드 0, 생성 없음)
- 유지(v2 승인): 칼, 몸 키(회전·무릎·숙임·발), 8·8·10f 16fps
- 몸: 파랑 회색 도형 = 몸통(어깨 → 골반 y80), 다리, 팔, 머리(왼쪽 1px). 몸통은 돌면 좁아짐
- 망토(빨강): 윗단은 어깨에 고정, 끝단 5점을 프레임마다 키로 줌 — 휘날림 s(+오른쪽), 앞쪽 들림 L, 앞쪽 퍼짐 f, 전체 들림 up. 뒤따라오는 끝이 휘날리는 쪽으로 더 끌려가 반대쪽 몸이 드러남. 몸보다 한 프레임 늦게 반응하고 넘쳤다 돌아오게 키를 넣음. 들린 끝단은 안감(진한 색)
  - 1타: f2~f3 몸이 왼쪽으로 틀 때 망토는 오른쪽에 남음 → f4 타격 때 왼쪽에 남겨짐 → f5~f6 오른쪽으로 크게 휘날리며 들림(왼다리 드러남) → f7~f8 내려옴
  - 2타: f2 낮게 고임 → f3~f5 왼쪽으로 뒤집혀 휘날림 → f6~f8 가라앉음
  - 3타: f2~f4 몸이 떨어질 때 망토는 위에 남아 벌어짐(다리 드러남) → f5 내려옴 → f6 기본보다 아래로 넘침 → f7~f9 작게 튀고 idle
- 수치(망토 중심 − 몸통 중심): −9.0 ~ +8.2px, 폭 27.6 ~ 38.0px (East −13 ~ +12, 21 ~ 39 / v2 −4 ~ 0, 34 ~ 35)
